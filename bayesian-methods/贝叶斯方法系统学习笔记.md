# 贝叶斯方法系统学习笔记：从条件概率到 Bayesian inference 与 MCMC

## 1. 贝叶斯到底是什么？

贝叶斯并不是某一个单独的算法。

它更像是一套关于：

> **如何在存在不确定性的情况下，用新数据更新我们对未知量的认识**

的完整推断框架。

最核心的思想可以写成：

```math
\boxed{
\text{原来的认识}
+
\text{新证据}
\rightarrow
\text{更新后的认识}
}
```

在贝叶斯统计里对应：

```math
\boxed{
\text{Prior}
+
\text{Likelihood}
\rightarrow
\text{Posterior}
}
```

即：

```math
\boxed{
\text{先验}
+
\text{似然}
\rightarrow
\text{后验}
}
```

这里的“+”表示信息的结合，不是普通的数值加法；严格的概率关系是后文的
$p(\theta\mid D)\propto p(D\mid\theta)p(\theta)$。

---

# 2. 先从条件概率开始

贝叶斯公式：

```math
P(A|B)
=
\frac{P(B|A)P(A)}{P(B)}
```

要理解这个公式，首先必须理解：

```math
P(A|B)
```

表示：

> 在已知 $B$ 发生的条件下，$A$ 发生的概率。

而：

```math
P(B|A)
```

表示：

> 在已知 $A$ 发生的条件下，$B$ 发生的概率。

这两个概率通常并不相同：

```math
\boxed{
P(A|B)\neq P(B|A)
}
```

---

# 3. 一个典型例子：疾病检测

设：

- $A$：患病；
- $B$：检测阳性。

假设：

```math
P(B|A)=0.90
```

表示：

> 患病的人中，有90%检测阳性。

这并不意味着：

```math
P(A|B)=0.90
```

也就是说：

> “阳性以后患病的概率”不等于“患病以后阳性的概率”。

---

## 3.1 为什么患病率也重要？

假设：

```math
P(A)=0.01
```

即患病率只有1%。

又假设：

```math
P(B|\neg A)=0.05
```

即健康人中有5%会出现假阳性。

想象有10000个人。

患病人数：

```math
10000\times0.01=100
```

其中90%阳性：

```math
100\times0.9=90
```

健康人数：

```math
9900
```

其中5%假阳性：

```math
9900\times0.05=495
```

因此所有阳性人数：

```math
90+495=585
```

其中真正患病：

```math
90
```

所以：

```math
P(A|B)
=
\frac{90}{585}
\approx0.154
```

即：

```math
15.4\%
```

虽然检测灵敏度是90%，但检测阳性后真正患病的概率只有约15.4%。

这是因为疾病本身非常罕见。

这体现了一个关键思想：

```math
\boxed{\text{Prior matters}}
```

也就是：

> 新证据不能脱离原本的基础概率来解释。

---

# 4. 贝叶斯公式为什么成立？

条件概率定义：

```math
P(A|B)
=
\frac{P(A\cap B)}{P(B)}
```

因此：

```math
P(A\cap B)
=
P(A|B)P(B)
```

同理：

```math
P(B|A)
=
\frac{P(A\cap B)}{P(A)}
```

所以：

```math
P(A\cap B)
=
P(B|A)P(A)
```

因为两个式子的左边相同：

```math
P(A|B)P(B)
=
P(B|A)P(A)
```

两边除以 $P(B)$：

```math
\boxed{
P(A|B)
=
\frac{P(B|A)P(A)}{P(B)}
}
```

所以贝叶斯公式本质上只是：

> 同一个联合事件 $A\cap B$ 可以从两个方向来计算。

---

# 5. 从事件概率进入统计建模

真正的贝叶斯统计通常不是在问：

```math
P(A|B)
```

而是在问：

```math
p(\theta|D)
```

其中：

- $\theta$：未知参数；
- $D$：已经观察到的数据。

例如在线性回归中：

```math
Y=\beta_0+\beta_1X+\epsilon
```

我们可能不知道：

```math
\beta_1
```

到底是多少。

于是：

```math
\theta=\beta_1
```

---

# 6. Frequentist 与 Bayesian 对参数的不同理解

## 6.1 Frequentist

频率学派认为：

```math
\theta
```

是：

> 一个固定但未知的真实值。

例如：

```math
\beta=0.6
```

这个真实值不会随机变化。

随机的是：

```math
\text{Data}
```

因为每次重新抽样，得到的数据不同。

---

## 6.2 Bayesian

贝叶斯并不是说真实参数本身会随时间随机变化。

而是说：

> 在我们不知道真实参数是多少时，可以用概率分布来表达自己的不确定性。

例如：

```math
\beta\sim N(0,1)
```

表示：

> 在看到当前数据之前，我们认为 $\beta$ 更可能靠近0，而极端大的值不太合理。

这里的概率是在描述：

```math
\boxed{\text{我们对未知参数的不确定性}}
```

---

# 7. Prior：先验分布

Prior 写作：

```math
p(\theta)
```

表示：

> 在看到当前数据以前，我们对参数 $\theta$ 的认识。

例如：

```math
\beta\sim N(0,1)
```

意味着：

- 0附近最合理；
- 1或-1仍然合理；
- 10或-10极不合理。

---

## 7.1 Prior 不等于“主观拍脑袋”

先验可以来自：

- 以前的研究；
- 领域知识；
- 已知的物理范围；
- 经验范围；
- 弱信息约束。

现代 Bayesian analysis 中非常常见的是：

```math
\boxed{\text{weakly informative prior}}
```

即：

> 不强迫结果落在某个很窄的范围，但排除明显不合理的极端值。

---

# 8. Likelihood：似然

Likelihood 写作：

```math
p(D|\theta)
```

意思是：

> 假设参数 $\theta$ 取某个值，现在观察到的数据 $D$ 有多合理。

例如：

```math
Y_i\sim N(\beta X_i,\sigma^2)
```

已经观察到：

```math
D=(X,Y)
```

我们可以比较不同：

```math
\beta
```

下数据的可能程度。

比如：

```math
\beta=0
```

可能无法很好解释数据。

```math
\beta=0.7
```

可能非常符合数据。

```math
\beta=10
```

可能又严重偏离数据。

因此Likelihood作为 $\beta$ 的函数，通常会在某些位置更高。

---

# 9. Likelihood 与 Probability 的区别

写：

```math
p(D|\theta)
```

如果把：

```math
\theta
```

固定，把 $D$ 看成变量，那么它是概率模型。

但在统计推断中：

- 数据 $D$ 已经观察到了；
- 我们改变 $\theta$；

此时：

```math
p(D|\theta)
```

作为 $\theta$ 的函数，就叫：

```math
\boxed{\text{Likelihood}}
```

它并不是：

```math
p(\theta|D)
```

因此：

```math
\boxed{
Likelihood \neq Posterior
}
```

---

# 10. Posterior：后验分布

Bayesian statistics 的核心是：

```math
\boxed{
p(\theta|D)
=
\frac{
p(D|\theta)p(\theta)
}{
p(D)
}
}
```

对应：

```math
\boxed{
Posterior
=
\frac{
Likelihood\times Prior
}{
Evidence
}
}
```

---

## 10.1 更常见的写法

由于对于已经观察到的数据 $D$：

```math
p(D)
```

对 $\theta$ 来说只是归一化常数，

所以经常写：

```math
\boxed{
p(\theta|D)
\propto
p(D|\theta)p(\theta)
}
```

即：

```math
\boxed{
Posterior
\propto
Likelihood
\times
Prior
}
```

这是 Bayesian inference 最重要的一条公式。

---

# 11. Posterior 可以理解成 Prior 和 Data 的结合

假设Prior认为：

```math
\beta\approx0
```

比较合理。

而Likelihood认为：

```math
\beta\approx1
```

最符合数据。

那么Posterior可能位于：

```math
\beta\approx0.8
```

附近。

所以可以直觉上理解为：

```math
\boxed{
Posterior
=
Prior和Data共同作用后的更新结果
}
```

但它不是简单的算术平均。

谁影响更大取决于：

- prior 有多集中；
- 数据量有多大；
- likelihood 有多集中。

---

# 12. 数据量与 Prior 的关系

当：

```math
n
```

很小时，数据提供的信息有限。

Likelihood通常较宽。

这时Prior的影响较明显。

而当：

```math
n
```

非常大时，Likelihood会越来越集中。

如果Prior不是极端不合理，那么：

```math
Posterior
```

通常越来越由数据决定。

因此：

```math
\boxed{
数据少
\Rightarrow
Prior影响更明显
}
```

```math
\boxed{
数据多
\Rightarrow
Likelihood通常占主导
}
```

---

# 13. 一个经典连续参数例子：抛硬币

假设：

```math
\theta=P(\text{正面})
```

我们不知道硬币是否公平。

---

## 13.1 Prior

例如：

```math
\theta\sim Beta(\alpha,\beta)
```

假设：

```math
\theta\sim Beta(10,10)
```

表示：

> 在看到数据之前，我们认为硬币更可能接近公平，即 $\theta=0.5$。

---

## 13.2 Likelihood

如果抛：

```math
n
```

次硬币，得到：

```math
x
```

次正面，那么：

```math
X\sim Binomial(n,\theta)
```

Likelihood：

```math
p(x|\theta)
=
\binom{n}{x}
\theta^x(1-\theta)^{n-x}
```

---

## 13.3 Posterior

Beta prior：

```math
\theta\sim Beta(\alpha,\beta)
```

配合Binomial likelihood 后：

```math
\theta|D
\sim
Beta(\alpha+x,\beta+n-x)
```

例如：

Prior：

```math
Beta(10,10)
```

数据：

```math
x=8,\quad n=10
```

则Posterior：

```math
\theta|D
\sim
Beta(18,12)
```

这就是一次完整的 Bayesian updating。

---

# 14. Conjugate Prior：共轭先验

如果某类Prior配合某个Likelihood之后，Posterior仍然属于同一个分布族，那么这个Prior叫：

```math
\boxed{\text{Conjugate Prior}}
```

例如：

```math
Beta + Binomial
\rightarrow Beta
```

这样数学上特别方便。

不过现代Bayesian analysis并不要求必须使用共轭先验。

复杂模型通常依赖数值计算。

---

# 15. MLE：Maximum Likelihood Estimation

频率学派常用：

```math
\boxed{
\hat\theta_{MLE}
=
\arg\max_\theta p(D|\theta)
}
```

意思是：

> 找到一个参数值，使当前观察到的数据最可能出现。

它只关注：

```math
Likelihood
```

而不使用Prior。

---

# 16. MAP：Maximum A Posteriori

Bayesian中，如果只寻找posterior最高的位置：

```math
\hat\theta_{MAP}
=
\arg\max_\theta
p(\theta|D)
```

因为：

```math
p(\theta|D)
\propto
p(D|\theta)p(\theta)
```

所以：

```math
\boxed{
\hat\theta_{MAP}
=
\arg\max_\theta
p(D|\theta)p(\theta)
}
```

因此：

```math
\boxed{
MLE = Likelihood only
}
```

而：

```math
\boxed{
MAP = \text{posterior mode}
}
```

在对数尺度上，MAP 优化等价于最大化
$\log p(D\mid\theta)+\log p(\theta)$，因此不能把 likelihood 和 prior 直接做普通数值相加。

如果Prior基本是平坦的：

```math
p(\theta)\approx constant
```

那么：

```math
MAP\approx MLE
```

---

# 17. Bayesian 与 Regularization 的关系

一个非常重要的联系是：

```math
\boxed{
Regularization
\leftrightarrow
Prior
}
```

## 17.1 Ridge Regression

Ridge：

```math
\min_\beta
\left[
\sum_i(y_i-\hat y_i)^2
+
\lambda\sum_j\beta_j^2
\right]
```

从Bayesian角度，如果：

```math
\beta_j\sim N(0,\tau^2)
```

Gaussian prior会倾向于让系数靠近0。

在高斯似然、误差尺度固定等条件下，其 MAP 估计与 Ridge 目标函数直接对应；惩罚系数还取决于先验尺度和观测噪声尺度。

## 17.2 LASSO

LASSO中的L1 penalty：

```math
\sum_j|\beta_j|
```

对应的Bayesian解释通常与Laplace prior相关。

在相同的高斯似然条件下，可以粗略记成：

- Ridge ↔ Gaussian prior；
- LASSO ↔ Laplace prior。

---

# 18. 为什么贝叶斯好像“哪里都能用”？

因为Bayesian不是一种固定模型结构。

它是一套：

```math
\boxed{\text{对模型未知参数进行概率推断的方法}}
```

因此同一个模型可以有：

- frequentist版本；
- Bayesian版本。

例如：

### Linear Regression

```math
Y=X\beta+\epsilon
```

可以变成Bayesian linear regression。

### Logistic Regression

```math
P(Y=1)=\sigma(X\beta)
```

可以变成Bayesian logistic regression。

### Mixed-effects Model

```math
Y=X\beta+Zu+\epsilon
```

可以变成Bayesian mixed model。

### Neural Network

```math
Y=f_\theta(X)
```

也可以给参数 $\theta$ 定义概率分布，形成Bayesian neural network。

所以：

```math
\boxed{
Bayesian不是一个具体预测器
}
```

而是：

```math
\boxed{
一种处理模型参数及其不确定性的推断框架
}
```

---

# 19. Bayes theorem、Bayesian inference、Naive Bayes 的区别

## Bayes theorem

一个概率恒等式：

```math
P(A|B)
=
\frac{P(B|A)P(A)}{P(B)}
```

## Bayesian inference

一套统计推断框架：

```math
Prior
+
Likelihood
\rightarrow
Posterior
```

## Naive Bayes

一个具体的分类算法。

它只是Bayesian思想中的一个应用。

---

# 20. Naive Bayes 的基本逻辑

假设：

```math
Y\in\{A,B\}
```

特征：

```math
X=(X_1,\ldots,X_p)
```

目标是：

```math
P(Y|X)
```

Bayes：

```math
P(Y|X)
\propto
P(X|Y)P(Y)
```

问题是：

```math
P(X_1,\ldots,X_p|Y)
```

很难直接估计。

Naive Bayes假设：

```math
X_1,\ldots,X_p
```

在给定类别 $Y$ 后条件独立。

因此（在给定类别 $Y$ 条件独立的假设下）：

```math
P(X_1,\ldots,X_p|Y)
=
\prod_{j=1}^{p}
P(X_j|Y)
```

所以：

```math
\boxed{
P(Y|X)
\propto
P(Y)
\prod_jP(X_j|Y)
}
```

这里：

```math
\prod_j
```

表示连乘。

例如：

```math
\prod_{j=1}^{3}a_j
=
a_1a_2a_3
```

---

# 21. Hierarchical Bayesian Model

Bayesian特别适合处理层级结构。

例如多个被试：

```math
j=1,\ldots,J
```

每个被试有自己的截距：

```math
\beta_{0j}
```

我们可以设：

```math
\beta_{0j}
\sim
N(\mu_\beta,\tau^2)
```

表示：

> 每个被试有自己的参数，但这些个体参数来自一个共同的总体分布。

同时：

```math
\mu_\beta
```

和：

```math
\tau
```

还可以拥有自己的prior。

例如：

```math
\mu_\beta\sim N(0,10)
```

```math
\tau\sim \mathrm{HalfNormal}(1)
```

形成层级结构：

```math
\text{population}
```

↓

```math
\text{subject-specific parameters}
```

↓

```math
\text{observations}
```

这就是：

```math
\boxed{\text{Hierarchical Bayesian Model}}
```

---

# 22. Partial Pooling

层级模型中的关键思想之一是：

```math
\boxed{\text{Partial Pooling}}
```

假设某个被试只有3个观测，他的个体估计会非常不稳定；另一个被试有100个观测，信息更充分。

Hierarchical model会：

- 对数据少的被试，让估计更多向总体均值收缩；
- 对数据多的被试，允许其个体估计更多由自身数据决定。

因此：

```math
\text{individual estimate}
\rightarrow
\text{group distribution}
```

但不是完全拉到总体均值。

这叫partial pooling。

它与mixed-effects model中的random effects思想密切相关。

---

# 23. 为什么复杂 Bayesian model 需要 MCMC？

简单模型有时可以直接写出：

```math
p(\theta|D)
```

但现实模型往往包含：

- 多个参数；
- random effects；
- nonlinearity；
- circular outcomes；
- hierarchical structure；
- latent variables。

此时：

```math
p(\theta|D)
```

可能没有简单的解析解。

于是需要数值方法来近似posterior。

最著名的一类就是：

```math
\boxed{\text{MCMC}}
```

Markov Chain Monte Carlo。

---

# 24. MCMC 的核心思想

我们想得到：

```math
p(\theta|D)
```

但无法直接求出完整分布。

MCMC的想法是：

> 想办法从这个posterior distribution中产生大量样本。

严格地说，有限长度的链只是对目标后验分布的近似；在满足遍历性等条件并经过足够长的运行后，样本分布才会趋近目标后验。

例如：

```math
\theta^{(1)},
\theta^{(2)},
\ldots,
\theta^{(5000)}
```

如果posterior在：

```math
\theta=2
```

附近概率密度很高，那么采样值会频繁出现在2附近。

如果：

```math
\theta=10
```

后验密度很低、该点附近的后验质量很小，那么就几乎不会采到该区域。

最终：

```math
\boxed{
\text{大量MCMC samples}
\approx
\text{Posterior distribution}
}
```

---

# 25. iterations = 5000 是什么意思？

例如：

```text
iterations = 5000
```

表示MCMC链运行了5000个迭代/采样步骤。

下面按“单条链、iterations 包含 warm-up”的简化情形说明。不同软件可能把 `iter`、`warmup` 和 warm-up 后的 draws 分开报告；多条链时还要结合链数计算总 draws。

得到：

```math
\theta^{(1)},
\theta^{(2)},
\ldots,
\theta^{(5000)}
```

这些并不是5000次独立实验，而是：

> 马尔可夫链在posterior空间中连续游走产生的样本。

---

# 26. burn-in = 1000 是什么意思？

例如：

```text
burn-in = 1000
```

在这个简化示例中，意味着：

> 最开始的1000个MCMC样本不用于最终posterior inference。

为什么？

因为MCMC必须从某个初始值开始。

例如：

```math
\theta^{(0)}=0
```

但posterior主要位于：

```math
\theta\approx2
```

那么链最开始可能经历：

```math
0
\rightarrow
0.4
\rightarrow
0.9
\rightarrow
1.3
\rightarrow
1.7
\rightarrow
2.0
\rightarrow\cdots
```

开始阶段明显受到initial value影响。

因此前面一段通常丢弃。

这段通常称为：

```math
\boxed{\text{burn-in}}
```

在带有步长或质量矩阵适配的 HMC 中，通常称为 warm-up；它除了减弱初始值影响，还包含采样器的适配阶段。

也常简称为：

```math
\boxed{\text{warm-up}}
```

---

# 27. iterations 与 burn-in 的关系

如果：

```text
iterations = 5000
burn-in = 1000
```

最简单的理解是：

总样本：

```math
5000
```

丢弃前：

```math
1000
```

最终保留：

```math
5000-1000=4000
```

个posterior samples。

即：

```math
\theta^{(1001)},
\ldots,
\theta^{(5000)}
```

---

# 28. 如何从 MCMC samples 得到参数估计？

假设保留4000个posterior samples：

```math
1.91,\ 2.03,\ 1.87,\ 2.12,\ldots
```

Posterior mean：

```math
E[\theta|D]
\approx
\frac{1}{4000}
\sum_s\theta^{(s)}
```

例如：

```math
\mathrm{Posterior\ Mean}=2.01
```

---

# 29. Credible Interval

将4000个样本排序。

取：

```math
2.5\%
```

和：

```math
97.5\%
```

分位数。

例如：

```math
[1.55,\ 2.46]
```

形成一个由 2.5% 和 97.5% 分位数构成的等尾区间：

```math
95\%\,\mathrm{credible\ interval}
```

Bayesian 95% credible interval可以解释为：

> 在当前模型、prior和data条件下，参数有95%的posterior probability位于这个区间。

这和 frequentist 95% confidence interval 的严格含义不同。

---

# 30. MCMC samples 并不是完全独立的

保留下来的4000个MCMC samples并不等于4000个独立样本。

因为Markov chain中：

```math
\theta^{(t)}
```

通常和：

```math
\theta^{(t+1)}
```

相关。

例如：

```math
1.91,\ 1.93,\ 1.90,\ 1.94,\ 1.96
```

这种连续相近的值很常见。

这种现象叫：

```math
\boxed{\text{autocorrelation}}
```

---

# 31. Effective Sample Size, ESS

因为 MCMC samples 存在自相关，在常见的正自相关情形下实际信息量可能远小于名义样本数；如果出现明显的负自相关，ESS 也可能高于名义 draws 数。

例如保留：

```math
4000
```

个MCMC samples，

但：

```math
ESS=1200
```

意味着：

> 这些4000个相关样本提供的信息量，大约相当于1200个独立样本。

因此：

```math
\boxed{
MCMC sample size
\neq
Effective Sample Size
}
```

---

# 32. Trace Plot

MCMC常见诊断之一是trace plot。

横轴：

```math
iteration
```

纵轴：

```math
\theta
```

理想情况下，burn-in之后：

- 链应该围绕一个稳定区域波动；
- 不应持续向上或向下漂移；
- 多条链应该探索同一个posterior区域。

如果trace plot表现很差，说明：

```math
\text{chain may not have converged}
```

---

# 33. $\hat R$：收敛诊断

Bayesian model通常运行多条MCMC chains。

例如4条链。

如果它们都收敛到同一个posterior distribution，那么链内和链间差异应该接近。

常用指标：

```math
\hat R
```

理想情况：

```math
\hat R\approx1
```

实践中通常要求它非常接近 1（许多工具把 1.01 左右作为警戒目标，但阈值取决于工具和应用场景）。明显大于 1 说明不同链可能还没有很好混合；R-hat 不能单独证明收敛，还应结合 ESS、trace plot 和模型诊断。

---

# 34. Thinning / lag

有些MCMC设置会出现：

```text
n.lag = 1
```

或：

```text
thin = 1
```

它与采样间隔有关。

例如：

```math
thin=2
```

可能表示：

> 每隔2个MCMC states保存一个。

历史上thinning常用于减少自相关和文件存储量。

但现代MCMC实践中通常不建议仅为了降低自相关就盲目大量thinning。

更重要的是：

- 足够长的链；
- 良好的采样算法；
- 检查ESS；
- 检查 $\hat R$；
- 检查trace plot。

# 35. MCMC 的常见算法

MCMC不是某一个具体算法，而是一大类方法。

常见包括：

- Metropolis-Hastings；
- Gibbs Sampling；
- Hamiltonian Monte Carlo；
- HMC；
- NUTS。

其中Stan、brms、PyMC等现代Bayesian工具经常使用：

```math
\boxed{\text{HMC / NUTS}}
```

对于光滑的连续参数后验，它们通常比简单 random-walk MCMC 更高效，但这不是对所有模型都成立。

# 36. Posterior 不只是一个点估计

Bayesian更自然的对象是：

```math
\boxed{p(\beta|D)}
```

即完整posterior distribution。

我们可以从中得到：

- posterior mean；
- posterior median；
- MAP；
- credible interval；
- $P(\beta>0|D)$；
- posterior predictive distribution。

这也是Bayesian analysis的重要特点：

> 参数不确定性本身就是结果的一部分。

---

# 37. Posterior Predictive Distribution

最终我们经常不只是关心参数：

```math
\theta
```

还关心未来数据：

```math
Y_{new}
```

Bayesian prediction写成：

```math
\boxed{
p(Y_{new}|D)
=
\int
p(Y_{new}|\theta,D)
p(\theta|D)
d\theta
}
```

如果给定参数后新数据与已观测数据条件独立，才可进一步写成
$p(Y_{new}\mid\theta,D)=p(Y_{new}\mid\theta)$。

直觉上：

> 对所有可能的参数值分别做预测，再根据这些参数在posterior中有多可信进行加权。

因此Bayesian prediction会自动把参数不确定性传播到预测不确定性。

# 39. 学 Bayesian 时最应该反复问的四个问题

## 1. 未知量是什么？

记作：

```math
\theta
```

例如：

- regression coefficient；
- variance；
- subject-specific effect；
- probability；
- latent variable。

## 2. Prior 是什么？

```math
p(\theta)
```

数据出现以前，我们如何描述它的合理范围？

## 3. Likelihood 是什么？

```math
p(D|\theta)
```

假设参数取某个值，观察到当前数据有多合理？

## 4. Posterior 是什么？

```math
p(\theta|D)
```

看到数据以后，我们对参数的不确定性变成什么样？

只要这四个问题始终清楚，绝大部分Bayesian模型就不会完全失去方向。

---

# 40. 最值得记住的两个公式

第一个：

```math
\boxed{
P(A|B)
=
\frac{
P(B|A)P(A)
}{
P(B)
}
}
```

它描述的是：

> 如何反转条件概率。

第二个：

```math
\boxed{
p(\theta|D)
\propto
p(D|\theta)p(\theta)
}
```

即：

```math
\boxed{
Posterior
\propto
Likelihood
\times
Prior
}
```

这是整个Bayesian statistics的核心。

# 42. 最后一句话理解 Bayesian

如果只用一句话记住整个Bayesian framework：

> **Bayesian inference就是用概率分布表达对未知参数的不确定性，然后利用观察到的数据把这种不确定性从Prior更新为Posterior。**

即：

```math
\boxed{
\text{Before data}
\rightarrow
\text{Data}
\rightarrow
\text{After data}
}
```

也就是：

```math
\boxed{
Prior
\rightarrow
Likelihood
\rightarrow
Posterior
}
```

以后无论遇到：

- Bayesian regression；
- Bayesian mixed-effects model；
- Bayesian circular model；
- Bayesian neural network；
- Bayesian classification；
- hierarchical Bayesian model；

都可以先退回到这一条最基本的逻辑线上重新理解。
