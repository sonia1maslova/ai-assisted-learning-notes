## 1. 基础概念与符号约定

### 1.1 图的基本类型

图（Graph）由节点和节点之间的边组成：

```math
G=(V,E).
```

- 无向图（Undirected Graph）：边不区分方向。
- 有向图（Directed Graph）：边区分方向，两个节点之间可以同时存在两个相反方向的边。
- 无权图（Unweighted Graph）：只记录边是否存在。
- 加权图（Weighted Graph）：每条边还带有数值，例如次数、时间或容量。
- 简单图（Simple Graph）：没有自环和重复边。

除非另有说明，本文默认简单无向图。涉及全图平均、概率分布等公式时要求节点集合非空；含 $n-1$ 或 $n(n-1)$ 分母的归一化公式要求 $n\ge2$。其他零分母情形按各节说明处理。讨论有向图时，规定邻接矩阵的元素满足：

```math
A_{ij}=1\quad\Longleftrightarrow\quad i\to j.
```

这一方向约定会影响特征向量中心性、Katz 中心性和有向模块度等公式中的矩阵转置。

### 1.2 统一符号

| 符号 | 含义 |
|---|---|
| $n=\lvert V\rvert$ | 节点数 |
| $m=\lvert E\rvert$ | 边数；无向边每条计一次 |
| $A$ | 无权邻接矩阵，存在边时为 1，否则为 0 |
| $W=(w_{ij})$ | 权重矩阵；无边处记为 0，存在零权边时须另存边的存在性 |
| $N(i)$ | 节点 $i$ 的邻居集合 |
| $k_i$ | 节点度 |
| $s_i$ | 节点强度 |
| $\ell_{ij}$ | 用于路径计算的边长或成本 |
| $d_{ij}=d(i,j)$ | 从 $i$ 到 $j$ 的最短路径距离 |
| $t_i$ | 包含节点 $i$ 的无向三角形数 |
| $T$ | 全图无向三角形总数 |
| $c_i$ | 节点 $i$ 的社区标签 |
| $w_\Sigma$ | 全图总边权；无向边每条计一次 |
| $\mathbf1$ | 全 1 列向量 |
| $I$ | 单位矩阵 |
| $\mathbf1\{\cdot\}$ | 示性函数：条件成立时为 1，否则为 0 |

本文的度、密度、距离、经典结构参数等基础定义，可结合教材 [1–2] 和官方算法文档 [3] 阅读。

### 1.3 边权含义必须先确定

| 边权类型 | 大值的含义 | 典型用途 |
|---|---|---|
| 联系强度 | 联系更强 | 强度、加权聚类、加权模块度、加权参与系数 |
| 距离、时间、成本 | 通行更困难 | 最短路径、接近中心性、效率、最短路径介数 |
| 容量 | 可承载更多流量 | 最大流、容量割 |
| 正负符号 | 关系性质不同 | 结构平衡、挫折指数 |

联系强度通常不能直接当作边长。模块度等强度型指标一般使用原始非负强度；最短路径指标则需要使用有实际含义的长度或成本。

本文的常规距离、效率和最短路径中心性，默认边长严格为正。零长度、负长度、零强度和负联系，应分别处理，不能机械套用同一规则。

## 2. 规模、连接与度分布

### 2.1 节点数与边数（Order and Size）

```math
n=|V|,\qquad m=|E|.
```

节点数描述网络包含多少对象，边数描述这些对象之间有多少连接。二者是解释其他指标的基础。

边数本身不能代表连接密集程度。例如，同样有 100 条边，20 个节点的网络与 1000 个节点的网络差别很大。

### 2.2 密度（Density）

简单无向图：

```math
\rho=\frac{m}{\binom n2}
=\frac{2m}{n(n-1)}.
```

简单有向图：

```math
\rho_{\mathrm{dir}}=\frac{m}{n(n-1)}.
```

密度表示实际连接数占所有可能连接数的比例。以上公式要求 $n\ge2$，取值在 $[0,1]$ 内。

加权密度（Weighted Density）没有唯一通用定义。如果所有权重满足 $0\le w_{ij}\le w_*$，且具有共同的正上限 $w_*$，可以明确规定：

```math
\rho_w=
\frac{2\sum_{\{i,j\}\in E}w_{ij}}
{n(n-1)w_*}.
```

它把无边记作零，同时考虑边的数量和强度。没有共同权重尺度时，不宜直接跨网络比较。

### 2.3 度、入度与出度（Degree, In-Degree and Out-Degree）

无向图的度：

```math
k_i=\sum_j A_{ij}.
```

度表示一个节点直接连接了多少个邻居。

有向图分别计算：

```math
k_i^{\mathrm{out}}=\sum_j A_{ij},
\qquad
k_i^{\mathrm{in}}=\sum_j A_{ji}.
```

总度（Total Degree）为：

```math
k_i^{\mathrm{tot}}=k_i^{\mathrm{in}}+k_i^{\mathrm{out}}.
```

总度中，一位双向邻居会贡献 2，因此总度不等于不同邻居的数量。

### 2.4 节点强度（Node Strength）

无向非负加权图：

```math
s_i=\sum_j w_{ij}.
```

有向图：

```math
s_i^{\mathrm{out}}=\sum_jw_{ij},
\qquad
s_i^{\mathrm{in}}=\sum_jw_{ji}.
```

度描述连接数量，强度描述连接总量。两位作者都可以有 10 位合作者，但累计合作次数不同。

节点强度保留权重的单位，一般没有统一的 $[0,1]$ 归一化。

### 2.5 平均度与平均强度（Average Degree and Average Strength）

无向图：

```math
\bar k=\frac1n\sum_i k_i=\frac{2m}{n}.
```

有向图：

```math
\overline{k^{\mathrm{in}}}
=\overline{k^{\mathrm{out}}}
=\frac mn.
```

无向加权图：

```math
\bar s=\frac1n\sum_i s_i=\frac{2w_\Sigma}{n}.
```

无向图中每条边贡献两个端点，因此度数之和为 $2m$，强度之和为 $2w_\Sigma$。

### 2.6 度分布、度方差与度变异系数（Degree Distribution, Degree Variance and Degree Coefficient of Variation）

度分布：

```math
p(k)=\frac{\#\{i:k_i=k\}}n.
```

它表示随机选择一个节点，其度为 $k$ 的概率。

度方差：

```math
\mathrm{Var}(k)=
\frac1n\sum_i(k_i-\bar k)^2.
```

度变异系数：

```math
CV_k=
\frac{\sqrt{\mathrm{Var}(k)}}{\bar k},
\qquad \bar k>0.
```

方差和变异系数衡量连接数量在节点之间是否均匀。出现少量高度节点，不能单独证明度分布服从幂律。

### 2.7 连通分量与最大连通分量比例（Connected Components and Largest Connected Component Fraction）

连通分量是节点可以相互到达、且不能再加入其他可达节点的最大节点集合。

常用指标包括分量数 $c$，以及：

```math
S_{\mathrm{LCC}}=\frac{|V_{\mathrm{LCC}}|}{n}.
```

最大连通分量比例描述最大的连通整体覆盖了多少节点。

有向图必须区分弱连通分量（Weakly Connected Component）与强连通分量（Strongly Connected Component）：前者忽略方向，后者要求任意两个节点都能沿方向相互到达。

### 2.8 可达率（Reachability Ratio）

```math
R_{\mathrm{reach}}=
\frac1{n(n-1)}
\sum_{i\ne j}\mathbf1\{d_{ij}<\infty\}.
```

可达率描述全部有序节点对中，存在通路的比例。有向图可以存在 $i$ 能到达 $j$，而 $j$ 不能到达 $i$ 的情况。

## 3. 距离、路径与效率

### 3.1 边长与最短路径距离（Edge Length and Shortest-Path Distance）

边长是直接跨越一条边的成本。节点间距离则考虑所有可行路径。

对路径 $P:i\leadsto j$：

```math
L(P)=\sum_{e\in P}\ell_e.
```

最短路径距离为：

```math
\boxed{
d_{ij}=\min_{P:i\leadsto j}\sum_{e\in P}\ell_e
}.
```

无权图令每条边长为 1。若不存在任何路径，则 $d_{ij}=\infty$。

即使两个节点直接相连，最短距离也不一定等于直接边长，因为绕行路线可能更短。

#### 3.1.1 成本型边权

如果 $w_{ij}$ 本身表示时间、路程或成本，可直接令：

```math
\ell_{ij}=w_{ij}.
```

例如：

```math
w_{AB}=5,\quad w_{BC}=5,\quad w_{AC}=1.
```

则：

```math
d_{AC}=\min(1,5+5)=1.
```

#### 3.1.2 强度型边权

如果 $w_{ij}>0$ 表示联系强度，一种常见转换是：

```math
\ell_{ij}=\frac1{w_{ij}},
```

从而：

```math
d_{ij}=
\min_{P:i\leadsto j}\sum_{(u,v)\in P}\frac1{w_{uv}}.
```

使用上面的相同数值：

```math
d_{AC}=
\min\left(1,\frac15+\frac15\right)=0.4.
```

此时，通过两条强联系连接，比直接通过一条弱联系连接更近。这是关系距离的解释，不是物理路程。

更一般的转换为：

```math
\ell_{ij}=w_{ij}^{-\alpha},
\qquad \alpha>0.
```

转换规则是建模选择，必须符合研究问题。不同规则可能改变最短路径。

#### 3.1.3 零权与负权

- “没有边”与“存在一条零权边”是不同情况，数据结构应能区分。
- 若强度为零，不能直接计算其倒数；应根据建图规则判断该边是否保留。
- 有向图在不存在相关负环时，可以计算含负边的最短路，但所得量不适合直接套入本文常规距离倒数、效率和中心性解释。
- 正负联系通常应使用有符号网络的方法，而不是把负联系机械转换成负长度。

### 3.2 平均最短路径长度（Average Shortest-Path Length）

```math
L=\frac1{n(n-1)}\sum_{i\ne j}d_{ij}.
```

无向图等价地写为：

```math
L=\frac1{\binom n2}\sum_{i<j}d_{ij}.
```

它表示随机选择两个不同节点时，平均需要走多远。

全图有限值要求无向图连通，或有向图强连通。不连通图可以分别计算各分量、只计算最大分量，或只平均可达节点对，但必须说明处理规则。

仅删除不可达节点对，可能使网络破碎后的平均距离反而下降，因此不能把下降自动解释为全图连通性改善。

### 3.3 Wiener 指数（Wiener Index）

对连通无向图：

```math
\mathrm{Wi}(G)=\sum_{i<j}d_{ij}.
```

它保留所有无序节点对的距离总和：

```math
L=\frac{\mathrm{Wi}(G)}{\binom n2}.
```

Wiener 指数同时受距离和节点对数量影响；跨规模网络比较时需要注意这一点。

### 3.4 离心率、直径与半径（Eccentricity, Diameter and Radius）

```math
e(i)=\max_jd_{ij},
```

```math
D_{\mathrm{diam}}=\max_i e(i),
\qquad
R_{\mathrm{rad}}=\min_i e(i).
```

- 离心率：节点到最远节点的距离。
- 直径：全图最远的一对节点之间的距离。
- 半径：选择最合适的出发节点后，到最远节点仍需走的距离。

离心率等于半径的节点构成图的中心（Graph Center）。

有向图可区分出向离心率 $\max_jd_{ij}$ 与入向离心率 $\max_jd_{ji}$。存在不可达节点时，相关最大值可能为无穷；软件也可能拒绝直接计算。

### 3.5 全局效率（Global Efficiency）

```math
E_{\mathrm{glob}}=
\frac1{n(n-1)}
\sum_{i\ne j}\frac1{d_{ij}},
\qquad
\frac1\infty:=0.
```

近距离点对贡献较大，远距离点对贡献较小，不可达点对贡献为 0。因此全局效率可以直接容纳不连通网络。[9]

全局效率一般不等于平均距离的倒数。所有节点对的距离均有限且为正时，由倒数函数的凸性可得：

```math
E_{\mathrm{glob}}\ge\frac1L.
```

只有所有不同节点对的距离相同时才取等号，例如边长均为 1 的完全图。前者先逐对取倒数再平均；后者先平均再取倒数。

无权图中 $0\le E_{\mathrm{glob}}\le1$。加权距离若小于 1，效率可能大于 1，并带有距离单位的倒数。需要统一单位或明确额外的归一化。

### 3.6 局部效率（Local Efficiency）

令 $G[N(i)]$ 是只保留节点 $i$ 的邻居，以及邻居之间边的诱导子图：

```math
E_{\mathrm{loc}}(i)=
\frac1{k_i(k_i-1)}
\sum_{\substack{j,h\in N(i)\\j\ne h}}
\frac1{d^{\,G[N(i)]}_{jh}}.
```

全图平均局部效率：

```math
E_{\mathrm{loc}}=\frac1n\sum_iE_{\mathrm{loc}}(i).
```

它描述邻居之间是否有替代通路。路径必须留在邻居子图中，不能使用整个 $G-i$ 的距离。通常将 $k_i<2$ 的局部效率记为 0。

有向与加权局部效率存在多种扩展，必须说明邻居集合、路径方向、边长和归一化方法。

实现提醒：NetworkX 的 global_efficiency 和 local_efficiency 常规函数忽略边权；使用其他库或后续版本时，也应核对具体实现。[3]

## 4. 节点与边的中心性

中心性（Centrality）对单个节点或边的位置评分。不同中心性使用不同机制：直接连接、最短路线、递归重要性或多通路分流。

### 4.1 度中心性（Degree Centrality）

```math
C_D(i)=\frac{k_i}{n-1}.
```

它表示节点直接连接了其他节点中的多大比例。简单无向图中取值为 $[0,1]$。

有向图：

```math
C_D^{\mathrm{in}}(i)=\frac{k_i^{\mathrm{in}}}{n-1},
\qquad
C_D^{\mathrm{out}}(i)=\frac{k_i^{\mathrm{out}}}{n-1}.
```

如果使用总度并希望归一化到 $[0,1]$，可除以 $2(n-1)$，但必须说明。自环或重复边可能使除以 $n-1$ 的结果超过 1。

### 4.2 网络中心化（Network Centralization）

中心性描述单个节点，中心化描述全图是否围绕少数节点组织。

简单无向图的度中心化：

```math
C_{\mathrm{cent},D}=
\frac{\sum_i(k_{\max}-k_i)}
{(n-1)(n-2)},
\qquad n>2.
```

分子累计各节点与最大度节点之间的差距，分母是同样节点数下最大的可能差距。星形图达到 1，正则图为 0。

其他中心性也能构造中心化，但最大差距和归一化分母需要按指标与图类型重新确定。

### 4.3 接近中心性（Closeness Centrality）

连通无向图：

```math
C_C(i)=
\frac{n-1}{\sum_{j\ne i}d_{ij}}.
```

它是平均最短距离的倒数。数值越高，表示节点平均离其他节点越近。

有向图：

```math
C_C^{\mathrm{out}}(i)=
\frac{n-1}{\sum_{j\ne i}d_{ij}},
\qquad
C_C^{\mathrm{in}}(i)=
\frac{n-1}{\sum_{j\ne i}d_{ji}}.
```

出向版本描述从节点出发的便利程度；入向版本描述别人到达该节点的便利程度。

#### 不连通修正（Wasserman–Faust Improved Closeness）

令 $R_i$ 为从 $i$ 可到达的其他节点集合， $r_i=|R_i|$：

```math
C_{WF}^{\mathrm{out}}(i)=
\frac{r_i}{n-1}
\frac{r_i}{\sum_{j\in R_i}d_{ij}}.
```

第一项按可达比例折减，第二项计算可达节点中的接近程度。孤立节点通常记为 0。入向版本使用能够到达 $i$ 的节点集合。[3]

### 4.4 调和中心性（Harmonic Centrality）

归一化出向版本：

```math
H(i)=
\frac1{n-1}
\sum_{j\ne i}\frac1{d_{ij}},
\qquad \frac1\infty=0.
```

不除以 $n-1$，得到未归一化版本。入向版本将 $d_{ij}$ 换成 $d_{ji}$。

接近中心性是平均距离的倒数；调和中心性是距离倒数的平均。后者可以自然容纳不可达节点。

在方向和距离定义相同的条件下：

```math
E_{\mathrm{glob}}=\frac1n\sum_iH(i).
```

### 4.5 节点介数中心性（Node Betweenness Centrality）

设 $\sigma_{st}$ 是 $s$ 到 $t$ 的最短路径条数， $\sigma_{st}(i)$ 是其中经过节点 $i$ 的条数。

无向图不计路径端点的原始介数：

```math
B(i)=
\sum_{\substack{s<t\\s,t\ne i}}
\frac{\sigma_{st}(i)}{\sigma_{st}}.
```

归一化：

```math
B_N(i)=\frac{B(i)}{\binom{n-1}{2}},
\qquad n>2.
```

不可达点对贡献记为 0。如果一个点对有两条最短路径，其中只有一条经过 $i$，该点对贡献 $1/2$。

有向图对有序点对求和，归一化除以 $(n-1)(n-2)$。

介数描述多少最短路线依赖节点。只有传播或运输接近最短路径机制时，才能进一步解释为中介作用；它不直接证明实际流量或因果影响。[4]

常见分支：

- 加权最短路径介数（Weighted Shortest-Path Betweenness）：使用边长计算最短路线。
- 计入端点介数（Endpoint-Inclusive Betweenness）：源点和终点也获得贡献，归一化随之改变。
- 子集介数（Subset Betweenness）：只统计特定来源和目标，需说明点对范围。
- 电流介数（Current-Flow Betweenness）：考虑多条通路共同分流，见第 9 节。

### 4.6 边介数中心性（Edge Betweenness Centrality）

```math
B(e)=
\sum_{s<t}\frac{\sigma_{st}(e)}{\sigma_{st}},
```

```math
B_N(e)=\frac{B(e)}{\binom n2}.
```

它描述多少最短路径经过一条边。边介数包含以边端点为源点或终点的点对，因此归一化分母不同于不计端点的节点介数。

有向版本使用有序点对，分母为 $n(n-1)$。加权版本使用路径边长。[3–4]

### 4.7 特征向量中心性（Eigenvector Centrality）

令 $M=A$ 表示无权图，或 $M=W$ 表示非负强度图。入向中心性满足：

```math
x_i=\frac1\lambda\sum_jM_{ji}x_j,
\qquad
M^\top x=\lambda x.
```

节点的分数由指向它的节点的分数共同决定。连接到高分节点，比连接到低分节点贡献更大。

通常采用主非负特征向量，并规定 $\sum_i x_i^2=1$ 等归一化。无向图中 $M^\top=M$；有向出向版本使用 $Mx=\lambda x$。

非负权图的支撑网络强连通时，主特征向量在倍数意义下唯一且为正。非强连通图可能出现零值或不唯一，不连通无向图也可能把分数集中在谱半径最大的分量。[2–3]

### 4.8 Katz 中心性（Katz Centrality）

```math
x=\alpha M^\top x+\beta\mathbf1,
```

```math
x=(I-\alpha M^\top)^{-1}\beta\mathbf1.
```

其中 $\beta>0$ 是基础分数， $\alpha\ge0$ 控制不同长度连接的贡献。通常要求：

```math
\alpha\rho(M)<1.
```

这里 $\rho(M)$ 是矩阵谱半径。满足条件时：

```math
x=
\sum_{\ell=0}^{\infty}
\alpha^\ell(M^\top)^\ell\beta\mathbf1.
```

每一项对应长度为 $\ell$ 的游走。游走允许重复经过节点和边，因此不是简单路径计数。

如果还要求系数 $\alpha^\ell$ 随长度下降，应另限定 $\alpha<1$；仅有收敛条件不必然推出这一点。部分定义会扣除零阶基础项，比较时应说明。[5]

### 4.9 PageRank（PageRank）

本节要求边权非负。对出强度大于零的节点：

```math
P_{ij}=\frac{w_{ij}}{s_i^{\mathrm{out}}}.
```

没有出边的节点称为悬挂节点（Dangling Node）。加权图中，出强度为零的节点即使存在零权出边，也无法按上式归一化，应作同样处理：把对应行补成概率分布。此后：

```math
\pi=\alpha P^\top\pi+(1-\alpha)q,
\qquad
\sum_i\pi_i=1,
\qquad 0\le\alpha<1.
```

$q$ 是非负、总和为 1 的重启分布。解释为：以概率 $\alpha$ 沿出边移动，以概率 $1-\alpha$ 按 $q$ 重新选择节点。长期访问比例构成分数。

常见分支包括普通 PageRank（Uniform PageRank）、个性化 PageRank（Personalized PageRank）和加权 PageRank（Weighted PageRank）。

PageRank 会按出强度分配贡献，因此一个有很多出边的节点，不会对每条边都贡献其全部分数。[6]

### 4.10 HITS 权威与枢纽分数（HITS Authority and Hub Scores）

设 $a$ 为权威分数， $h$ 为枢纽分数：

```math
a\propto M^\top h,
\qquad
h\propto Ma.
```

所以：

```math
a\propto M^\top Ma,
\qquad
h\propto MM^\top h.
```

好的权威节点被好的枢纽指向，好的枢纽指向好的权威节点。例如，内容来源可以有高权威分数，优质来源目录可以有高枢纽分数。

主奇异值有重数时，分数可能不唯一；迭代计算还需要检查收敛。[7]

### 4.11 核数、核层与退化度（Core Number, k-Shell and Degeneracy）

$k$-核（k-Core）是内部每个节点的度都至少为 $k$ 的最大诱导子图。

节点核数：

```math
\mathrm{core}(i)=
\max\{k:i\in V(G_k)\}.
```

核层是核数恰好为 $k$ 的节点集合。图的退化度为：

```math
\mathrm{degeneracy}(G)=
\max_i\mathrm{core}(i).
```

反复删除当前度小于 $k$ 的节点，可以得到 $k$-核。星形图中心虽然度高，但所有节点核数都为 1。

有向图可定义总度核，或要求内部入度、出度同时达到下限的 $(k_{\mathrm{in}},k_{\mathrm{out}})$-核。不同版本不能混写。[8]

## 5. 局部聚集、相似性与结构洞

### 5.1 局部聚类系数（Local Clustering Coefficient）

```math
C_i=
\frac{t_i}{\binom{k_i}{2}}
=\frac{2t_i}{k_i(k_i-1)}.
```

它表示节点的邻居之间，实际存在的边占可能边数的比例。例如 4 位邻居之间最多有 6 条边，实际有 3 条，则 $C_i=1/2$。

通常将 $k_i<2$ 的节点记为 0。[10]

### 5.2 平均局部聚类系数（Average Local Clustering Coefficient）

```math
\bar C=\frac1n\sum_iC_i.
```

它让每个节点拥有相同权重。若只平均度至少为 2 的节点，或只平均非零值，结果会改变，必须注明。

### 5.3 三角形数与传递性（Triangle Count and Transitivity）

简单无向图的三角形总数：

```math
T=\frac{\mathrm{tr}(A^3)}6.
```

传递性，也常称全局聚类系数（Global Clustering Coefficient）：

```math
C_T=
\frac{3T}{\sum_i\binom{k_i}{2}}.
```

分母统计以一个节点为中心的邻居对；每个三角形贡献三个闭合邻居对。

它与局部聚类的关系为：

```math
C_T=
\frac{\sum_i\binom{k_i}{2}C_i}
{\sum_i\binom{k_i}{2}}.
```

因此传递性是按邻居对数量加权的平均，高度节点的影响更大。一般有 $C_T\ne\bar C$。不存在任何邻居对时，原式无定义，软件可能约定为 0。[2–3]

### 5.4 加权聚类系数（Weighted Clustering Coefficient）

#### Onnela 型加权聚类（Onnela Weighted Clustering）

令 $\hat w_{ij}=w_{ij}/w_{\max}$，对有序的 $j,h$ 求和：

```math
C_i^O=
\frac1{k_i(k_i-1)}
\sum_{j\ne h}
(\hat w_{ij}\hat w_{ih}\hat w_{jh})^{1/3}.
```

没有边时权重记为 0。它使用三角形三条边的几何平均，其中一条边很弱，就会降低整个三角形的贡献。

全图最大权重变化，也可能改变其他节点的归一化值。[12]

#### Barrat 型加权聚类（Barrat Weighted Clustering）

```math
C_i^B=
\frac1{s_i(k_i-1)}
\sum_{j\ne h}
\frac{w_{ij}+w_{ih}}2
A_{ij}A_{ih}A_{jh}.
```

它关注节点 $i$ 自己的强联系是否参与闭合三角形，不使用闭合边 $jh$ 的权重。

两种定义回答的问题不同，不能直接互换。公式要求相关分母为正，退化情况应明确约定。[11]

### 5.5 有向聚类系数（Directed Clustering Coefficient）

记：

```math
k_i^{\leftrightarrow}=
\sum_jA_{ij}A_{ji},
```

即与节点 $i$ 双向相连的邻居数。

一种合并全部方向模式的有向聚类为：

```math
C_i^D=
\frac{[(A+A^\top)^3]_{ii}}
{2[k_i^{\mathrm{tot}}(k_i^{\mathrm{tot}}-1)
-2k_i^{\leftrightarrow}]}.
```

矩阵三次幂表示矩阵乘法，不能替换为每个元素分别取三次方。[13]

有向三角形还可以按参考节点的角色分为：

| 分支 | 实际模式计数 $t_i^*$ | 可能模式计数 $T_i^*$ |
|---|---|---|
| 循环型（Cycle） | $(A^3)_{ii}$ | $k_i^{\mathrm{in}}k_i^{\mathrm{out}}-k_i^{\leftrightarrow}$ |
| 中介型（Middleman） | $(AA^\top A)_{ii}$ | $k_i^{\mathrm{in}}k_i^{\mathrm{out}}-k_i^{\leftrightarrow}$ |
| 双入型（In） | $(A^\top A^2)_{ii}$ | $k_i^{\mathrm{in}}(k_i^{\mathrm{in}}-1)$ |
| 双出型（Out） | $(A^2A^\top)_{ii}$ | $k_i^{\mathrm{out}}(k_i^{\mathrm{out}}-1)$ |

各分支使用：

```math
C_i^*=\frac{t_i^*}{T_i^*}.
```

有向加权扩展先构造 $B_{ij}=(w_{ij}/w_{\max})^{1/3}$，再在分子中用 $B$ 替换 $A$，分母仍使用二元连接的度数。分母为零时常约定为 0。[13]

### 5.6 邻居相似性指标（Neighborhood Similarity Measures）

共同邻居数（Common Neighbors）：

```math
CN(i,j)=|N(i)\cap N(j)|.
```

Jaccard 系数（Jaccard Coefficient）：

```math
J(i,j)=
\frac{|N(i)\cap N(j)|}{|N(i)\cup N(j)|}.
```

Adamic–Adar 指数（Adamic–Adar Index）：

```math
AA(i,j)=
\sum_{z\in N(i)\cap N(j)}\frac1{\log k_z}.
```

资源分配指数（Resource Allocation Index）：

```math
RA(i,j)=
\sum_{z\in N(i)\cap N(j)}\frac1{k_z}.
```

共同邻居描述共享联系数；Jaccard 控制邻居集合规模；后两者降低高度共同邻居的贡献。

这些公式默认简单无向图与两个不同节点。有向图需明确使用共同入邻居、共同出邻居，还是忽略方向后的邻居。Jaccard 并集为空时需要说明约定。[3]

### 5.7 有效规模（Effective Size）

结构洞（Structural Hole）指不同关系圈之间缺少直接连接的空隙。连接这些关系圈的节点，可能接触较少重复的信息。

简单无向无权图的有效规模：

```math
E_i=k_i-\frac{2m_i}{k_i},
\qquad k_i>0.
```

$m_i$ 是邻居之间的边数，不包含连接节点 $i$ 本身的边。

邻居之间完全无边时 $E_i=k_i$；邻居全部互连时 $E_i=1$。它描述扣除重复关系后的有效联系规模。[3]

### 5.8 约束系数（Constraint）

无向非负加权图，令：

```math
p_{ij}=\frac{w_{ij}}{s_i},\qquad s_i>0.
```

计算间接关系时，可将零强度节点对应的整行 $p_{qj}$ 约定为 0；零强度节点自身的约束值不由下面的归一化定义给出，应标为未定义，或明确报告软件采用的约定。

对正强度节点，约束系数为：

```math
\mathrm{Constraint}(i)=
\sum_{j\in N(i)}
\left(p_{ij}+\sum_qp_{iq}p_{qj}\right)^2.
```

公式同时考虑直接关系与通过邻居形成的间接关系。较高值通常表示联系集中、关系重复程度较高；较低值表示联系相对分散。

该简写限定无向图。有向版本需先说明互惠关系合并及归一化方式。约束低不直接证明节点实际获得了信息优势。[3]

## 6. 同配性、互惠性与富人俱乐部

### 6.1 度同配性（Degree Assortativity）

```math
r_k=\mathrm{Corr}(k_U,k_V).
```

把边的两个端点度数构成样本，计算相关系数。无向图应将每条边的两个方向均纳入样本，避免任意端点排序影响结果。

- $r_k>0$：高度节点较倾向连接高度节点。
- $r_k<0$：高度节点较倾向连接低度节点。
- $r_k=0$：没有这种线性相关，不表示没有其他结构依赖。

端点度数方差为零时，相关系数无定义。

有向图有四种组合：

```math
r_{\alpha,\beta}=
\mathrm{Corr}(k_U^\alpha,k_V^\beta),
\qquad
\alpha,\beta\in\{\mathrm{in},\mathrm{out}\}.
```

例如出—入同配性比较源节点出度与目标节点入度。[14]

### 6.2 属性同配性（Attribute Assortativity）

数值属性同配性（Numeric Assortativity）可以对边两端的数值属性计算相关系数。

类别属性同配性（Categorical Assortativity）使用类别混合矩阵。令 $e_{ab}$ 为起点属类别 $a$、终点属类别 $b$ 的样本比例，定义：

```math
a_a=\sum_be_{ab},\qquad b_a=\sum_be_{ba}.
```

则：

```math
r_{\mathrm{cat}}=
\frac{\sum_ae_{aa}-\sum_aa_ab_a}
{1-\sum_aa_ab_a}.
```

它比较实际同类连接比例与类别占比决定的参照比例。分母为零时无定义。[14]

加权时，按边权加权采样和仅把度换成强度是不同操作，必须说明采用哪一种。

### 6.3 互惠性（Reciprocity）

简单有向图：

```math
r_{\mathrm{rec}}=
\frac{\sum_{i\ne j}A_{ij}A_{ji}}m,
\qquad m>0.
```

它表示全部有向边中，有反向边与之配对的比例。一对双向边贡献 2。

一种加权互惠性（Weighted Reciprocity）为：

```math
r_{\mathrm{rec}}^w=
\frac{\sum_{i\ne j}\min(w_{ij},w_{ji})}
{\sum_{i\ne j}w_{ij}}.
```

此式要求边权非负，且有向总边权大于零；无边处取零。它描述双向流量能够匹配的比例，不直接表示超过随机期望的互惠倾向。加权互惠性也存在其他定义，应同时报告公式。[32]

### 6.4 富人俱乐部系数（Rich-Club Coefficient）

#### 6.4.1 直观问题与成员选择

它回答：连接较多的节点，彼此之间是否连接紧密？

“富”在标准度版本中仅表示度高，不自动表示财富、影响力或社区身份。富节点可能分属不同社区。

成员筛选与连接评价是两个独立步骤：可以按度或强度选择成员，也可以分别评价二元连接与边权配置。

#### 6.4.2 原始无权公式

选择度严格大于阈值 $k$ 的节点：

```math
V_{>k}=\{i:k_i>k\}.
```

成员数为 $N_{>k}$，内部边数为 $E_{>k}$：

```math
\boxed{
\phi(k)=
\frac{2E_{>k}}{N_{>k}(N_{>k}-1)}
}.
```

它就是成员子图的密度，要求 $N_{>k}\ge2$。注意不能混用 $>k$ 和 $\ge k$。[15]

系数通常随多个阈值计算，形成一条曲线。曲线上升本身不能证明存在超出度约束的富人俱乐部效应。

#### 6.4.3 随机参照与归一化

高度节点本来就有更多连接机会。常用参照保持每个节点的度不变，随机重排连接：

```math
\phi_{\mathrm{norm}}(k)=
\frac{\phi_{\mathrm{obs}}(k)}
{\mathbb E_{\mathrm{null}}[\phi(k)]}.
```

- 大于 1：超过所选参照均值。
- 等于 1：与参照均值一致。
- 小于 1：低于参照均值。

超过均值不自动表示统计显著。还需查看随机分布、单侧检验及多个阈值带来的多重比较问题。

参照均值为零时，归一化比值无定义。阈值过高、只剩少量成员时，结果尤其不稳定。[15]

#### 6.4.4 加权富人俱乐部系数（Weighted Rich-Club Coefficient）

一种常用定义是：

```math
\boxed{
\phi^w(r)=
\frac{W_{>r}}
{\sum_{\ell=1}^{E_{>r}}w_{(\ell)}}
}.
```

$r$ 是成员筛选阈值， $W_{>r}$ 是成员之间总边权， $w_{(\ell)}$ 是全图按降序排列的边权。

分母表示：若把全图最强的 $E_{>r}$ 条边放在成员之间，总权重能达到多少。

例如，成员间三条边权为 $8,6,4$，而全图最强三条边为 $10,9,8$：

```math
\phi^w=\frac{8+6+4}{10+9+8}=\frac23.
```

该版本衡量已有内部边的强度配置，不是密度。全图等权、且俱乐部存在内部边时，原始加权系数恒为 1；没有内部边时原式为 $0/0$，需另作约定。[16]

加权归一化还需要相应参照：

```math
\phi_{\mathrm{norm}}^w(r)=
\frac{\phi_{\mathrm{obs}}^w(r)}
{\mathbb E_{\mathrm{null}}[\phi^w(r)]}.
```

固定拓扑后打乱权重，与同时随机化连接和权重，回答不同问题。按强度选成员时，还要避免随机化改变成员身份而未加说明。

#### 6.4.5 有向扩展

简单有向图中，若仍以成员内部有向边密度评价：

```math
\phi_{\mathrm{dir}}(r)=
\frac{E_{>r}}{N_{>r}(N_{>r}-1)}.
```

需要说明成员按入度、出度、总度或相应强度选择。不能继续使用无向图的系数 2。

## 7. 社区结构、模块度与参与系数

### 7.1 社区与划分

社区（Community）或模块（Module）是内部连接相对集中的节点组。本文默认社区互不重叠，并覆盖全部节点。

模块度评价整个划分，参与系数评价节点相对于该划分的连接分布。社区检测算法负责寻找划分，与这两个指标本身不同。

### 7.2 模块度（Modularity）

#### 7.2.1 核心思想

模块度衡量：

> 实际社区内部连接，比根据节点度数得到的参照水平，多出多少。

只统计内部边数量并不充分，因为高度节点即使随机连接，也容易形成较多内部边。

#### 7.2.2 社区求和式

以下无权模块度公式要求 $m>0$；空边图的原式无定义。标准版本：

```math
\boxed{
Q=
\sum_S
\left[
\frac{m_S}{m}
-
\left(\frac{K_S}{2m}\right)^2
\right]
}.
```

$m_S$ 是社区内部边数，每条计一次； $K_S=\sum_{i\in S}k_i$ 是该社区节点的全图总度，包括通向外部的边。

第一项为实际内部边占全图边数的比例。第二项是标准度乘积参照模型的内部连接占比基准。

全图共有 $2m$ 个边端点，某社区占据的比例是 $K_S/(2m)$，因此基准写成该比例的平方。[17–18]

#### 7.2.3 节点对形式

```math
Q=
\frac1{2m}
\sum_{i,j}
\left(
A_{ij}-\frac{k_ik_j}{2m}
\right)
\delta(c_i,c_j).
```

同社区时 $\delta=1$，否则为 0。对全部 $i,j$ 求和时，每条无向边计两次，因此分母为 $2m$。

标准节点对公式保留 $i=j$ 的参照项，即使简单图中 $A_{ii}=0$。

$k_ik_j/(2m)$ 是标准解析基准，不是所有保度简单随机图中的精确连边概率；它甚至可能超过 1，不能直接当作概率解释。

#### 7.2.4 如何解释数值

- $Q>0$：该划分的内部连接总体超过指定基准。
- $Q=0$：没有净超额，但不证明图不存在社区。
- $Q<0$：该划分的内部连接低于基准。

模块度不是概率，也不是内部边百分比。在 $\gamma=1$ 时，把全图放在一个社区可得 $Q=0$。

同一张图可以因划分不同而得到多个值。若报告“该网络的模块度”，必须说明对应划分以及寻找该划分的方法。

#### 7.2.5 带分辨率的模块度（Generalized Modularity）

```math
Q_\gamma=
\frac1{2m}
\sum_{i,j}
\left(
A_{ij}-\gamma\frac{k_ik_j}{2m}
\right)
\delta(c_i,c_j).
```

等价地：

```math
Q_\gamma=
\sum_S
\left[
\frac{m_S}{m}
-
\gamma\left(\frac{K_S}{2m}\right)^2
\right].
```

$\gamma=1$ 是常用版本。优化划分时，较小的 $\gamma$ 通常偏向较大社区，较大的 $\gamma$ 偏向较小社区。不同 $\gamma$ 的原始分数不应直接当作相同标尺比较。[30]

#### 7.2.6 加权模块度（Weighted Modularity）

非负加权无向图：

```math
Q_\gamma^w=
\frac1{2w_\Sigma}
\sum_{i,j}
\left(
w_{ij}-\gamma\frac{s_is_j}{2w_\Sigma}
\right)
\delta(c_i,c_j).
```

若 $w_S$ 是社区内部总边权， $S_S=\sum_{i\in S}s_i$：

```math
Q_\gamma^w=
\sum_S
\left[
\frac{w_S}{w_\Sigma}
-
\gamma\left(\frac{S_S}{2w_\Sigma}\right)^2
\right].
```

这里使用联系强度，不先转为最短路径距离。要求 $w_\Sigma>0$。

#### 7.2.7 有向模块度（Directed Modularity）

```math
Q_\gamma^{\mathrm{dir}}=
\frac1m
\sum_{i,j}
\left(
A_{ij}-
\gamma\frac{k_i^{\mathrm{out}}k_j^{\mathrm{in}}}{m}
\right)
\delta(c_i,c_j).
```

有向加权版本把度换成相应强度，把 $m$ 换成有向总边权。[3]

#### 7.2.8 主要局限

- 高模块度不自动证明社区具有实际意义，随机图优化后也可能出现正模块度。
- 模块度优化有分辨率限制（Resolution Limit），可能合并实际存在的小社区。[19]
- Louvain 和 Leiden 等是寻找划分的算法，可能优化模块度，也可能优化其他目标；应报告实际目标函数。
- 不同运行可能得到分数接近、但节点归属不同的划分，需要检查稳定性。
- 带负边的网络需要专门的有符号定义，不能把负强度直接代入普通非负版本。

### 7.3 参与系数（Participation Coefficient）

#### 7.3.1 公式与含义

令节点 $i$ 连接到社区 $S$ 的边数为 $k_{iS}$：

```math
k_i=\sum_Sk_{iS}.
```

参与系数为：

```math
\boxed{
P_i=
1-\sum_S
\left(\frac{k_{iS}}{k_i}\right)^2
},
\qquad k_i>0.
```

它衡量节点连接在各社区之间分散得是否均匀，而不是外部连接数量。[20]

令 $p_{iS}=k_{iS}/k_i$。从节点的邻接边中独立、有放回地抽两次，两次目标属于同一社区的概率为 $\sum_Sp_{iS}^2$。因此 $P_i$ 是两次目标分属不同社区的概率。

#### 7.3.2 计算示例

| 各社区连接数 | 参与系数 |
|---|---:|
| $(6,0,0)$ | $0$ |
| $(3,3,0)$ | $1/2$ |
| $(2,2,2)$ | $2/3$ |
| $(4,1,1)$ | $1/2$ |

连接涉及更多社区，不保证参与系数一定更高，还取决于分配是否均匀。

#### 7.3.3 上限与退化情形

若能均匀分配到全部 $M$ 个社区：

```math
P_{\max}=1-\frac1M.
```

两个社区的理论上限是 $1/2$，三个是 $2/3$，有限社区数下不会达到 1。

无权节点最多连接 $\min(M,k_i)$ 个社区，还受整数分配与社区容量限制，因此实际可达上限可能更低。度为 1 时参与系数恒为 0。

$P_i=0$ 的准确含义是所有边集中在某一个社区，未必是节点自己的社区。孤立节点原式无定义，软件可能约定为 0。

#### 7.3.4 与外部连接比例的区别

假设节点属于社区 1：

| 本社区边数 | 另一社区边数 | 外部连接比例 | $P_i$ |
|---:|---:|---:|---:|
| 8 | 2 | $0.2$ | $0.32$ |
| 2 | 8 | $0.8$ | $0.32$ |
| 0 | 10 | $1$ | $0$ |

前两行的分散程度相同；第三行虽然全部连接到外部，但目标集中在一个社区，因此参与系数为 0。

#### 7.3.5 加权参与系数（Weighted Participation Coefficient）

```math
P_i^w=
1-\sum_S
\left(\frac{s_{iS}}{s_i}\right)^2,
```

```math
s_{iS}=\sum_{j\in S}w_{ij},
\qquad
s_i=\sum_Ss_{iS}.
```

它描述总联系强度在各社区之间的分配，要求非负权重且 $s_i>0$。

#### 7.3.6 入向与出向参与系数（In-Participation and Out-Participation Coefficients）

```math
P_i^{\mathrm{out}}=
1-\sum_S
\left(
\frac{k_{iS}^{\mathrm{out}}}{k_i^{\mathrm{out}}}
\right)^2,
```

```math
P_i^{\mathrm{in}}=
1-\sum_S
\left(
\frac{k_{iS}^{\mathrm{in}}}{k_i^{\mathrm{in}}}
\right)^2.
```

有向加权版本再替换为相应的入强度或出强度。方向与零分母处理必须说明。

#### 7.3.7 划分依赖与解释限制

参与系数依赖社区划分。将一个既有社区细分时，若某个连接份额从 $a+b$ 分为 $a,b$，参与系数增加：

```math
(a+b)^2-a^2-b^2=2ab\ge0.
```

因此，仅细分社区而不改变任何边，也可能提高参与系数。

跨网络比较时，应考虑社区数量、社区大小、节点度和划分分辨率。高参与系数不直接表示高影响力，还应结合度、强度和传播机制。[29]

### 7.4 社区内度标准分（Within-Module Degree z-Score）

```math
z_i=
\frac{k_{i,c_i}-\mu_{c_i}}
{\sigma_{c_i}}.
```

$\mu_{c_i}$ 和 $\sigma_{c_i}$ 分别是该社区各节点社区内度的均值和标准差。

$z_i$ 高表示节点在自己社区内部连接较多； $P_i$ 高表示连接分布较分散。二者可以共同描述内部枢纽与跨社区连接者。

标准差为零时原式无定义。加权版本可使用社区内部强度，并说明标准差计算约定。[20]

### 7.5 割边数、导通率与归一化割（Cut Size, Conductance and Normalized Cut）

对节点集合 $S$ 和补集 $\bar S$：

```math
\mathrm{cut}(S,\bar S)=
\sum_{i\in S,j\in\bar S}A_{ij}.
```

体积（Volume）：

```math
\mathrm{vol}(S)=\sum_{i\in S}k_i.
```

导通率：

```math
\phi_{\mathrm{cond}}(S)=
\frac{\mathrm{cut}(S,\bar S)}
{\min\{\mathrm{vol}(S),\mathrm{vol}(\bar S)\}}.
```

归一化割：

```math
\mathrm{Ncut}(S,\bar S)=
\mathrm{cut}(S,\bar S)
\left(
\frac1{\mathrm{vol}(S)}
+
\frac1{\mathrm{vol}(\bar S)}
\right).
```

在分母为正时，较小值表示两侧之间的连接相对较少，可用于寻找社区边界或网络瓶颈。

加权版本用权重计算割，用强度计算体积。有些文献采用单侧归一化导通率，需要核对定义。[1–3]

## 8. 模体与小世界

### 8.1 模体计数与模体标准分（Motif Count and Motif z-Score）

小型子图模式包括三角形、有向循环和前馈结构。部分文献广义地把这些模式称为网络模体（Network Motif）；Milo 等提出的严格统计定义则要求：该模式相对指定随机参照显著过度出现。因此，仅有原始计数或较高的标准分，不能直接证明一种模式是统计意义上的模体。[31]

原始计数为 $N_H$。与随机参照比较时：

```math
Z_H=
\frac{N_H^{\mathrm{obs}}-\mu_H^{\mathrm{null}}}
{\sigma_H^{\mathrm{null}}}.
```

较大值表示该模式比参照模型更常见。参照标准差为零时，原式无定义。

需要说明：

- 计数诱导子图还是一般子图。
- 重叠模式是否分别计数。
- 随机参照保留哪些特征。
- 同时检验多种模式时如何处理多重比较。

标准分不是自动有效的显著性结论。[2–3]

### 8.2 小世界系数 sigma（Small-World Coefficient Sigma）

```math
\sigma_{\mathrm{SW}}=
\frac{\bar C/\bar C_{\mathrm{rand}}}
{L/L_{\mathrm{rand}}}.
```

它结合相对较高的聚类和相对较短的路径。 $\sigma_{\mathrm{SW}}>1$ 常用作经验判据，但结果依赖参照模型和随机图的聚类水平。[10,21]

必须说明聚类使用 $\bar C$ 还是传递性，并在原图与参照图中保持一致。

### 8.3 小世界系数 omega（Small-World Coefficient Omega）

```math
\omega_{\mathrm{SW}}=
\frac{L_{\mathrm{rand}}}L
-
\frac{\bar C}{\bar C_{\mathrm{latt}}}.
```

- 接近 0：兼有短路径与高聚类。
- 负值：更偏向规则格子。
- 正值：更偏向随机网络。

需要说明随机图和规则格子参照如何生成，是否保持规模、度序列与连通性。分母需为正，路径指标还需有一致的不连通处理。[22]

<a id="sec-09"></a>
## 9. 谱、电阻与可通信性

### 9.1 邻接谱半径（Adjacency Spectral Radius）

```math
\rho(M)=\max_j|\lambda_j(M)|.
```

谱指矩阵的特征值集合。谱半径出现在 Katz 收敛条件、线性传播及某些动力学稳定性分析中。

它的意义取决于具体传播模型，不能统一解释为“越大，所有传播都越快”，也不能把其倒数当作所有传播过程的精确阈值。[2]

### 9.2 代数连通度（Algebraic Connectivity）

无向非负加权图的拉普拉斯矩阵（Graph Laplacian）为：

```math
\mathcal L=D_s-W,
\qquad
(D_s)_{ii}=s_i.
```

特征值按序排列：

```math
0=\mu_1\le\mu_2\le\cdots\le\mu_n.
```

代数连通度：

```math
a(G)=\mu_2,\qquad n\ge2.
```

正权支撑图连通时 $a(G)>0$，不连通时为 0。小值通常反映薄弱连接。

它不同于节点连通度和边连通度。统一放大全部权重，会使未归一化的代数连通度同倍变化。[2–3]

### 9.3 归一化拉普拉斯谱（Normalized Laplacian Spectrum）

```math
\mathcal L_{\mathrm{norm}}=
D_s^{-1/2}\mathcal L D_s^{-1/2}.
```

零度节点对应的逆平方根元素通常约定为 0。此定义下，其特征值位于 $[0,2]$。

它能消除统一放大全部边权的尺度影响，但不保证任意不同网络都可直接比较。

存在孤立节点时，不应未经说明就把上述式子改写成对全部节点都采用单位对角线的 $I-D_s^{-1/2}WD_s^{-1/2}$。[3]

### 9.4 有效电阻（Effective Resistance）

对连通无向正电导网络：

```math
R_{ij}^{\mathrm{eff}}=
\mathcal L^+_{ii}
+
\mathcal L^+_{jj}
-
2\mathcal L^+_{ij}.
```

$\mathcal L^+$ 是拉普拉斯矩阵的广义逆。边权在这里表示电导，边电阻为其倒数。

有效电阻考虑替代通路共同分流。增加一条较长的并联通路，可能不改变最短距离，却降低有效电阻。[2–3]

实现提醒：`NetworkX.resistance_distance` 默认将输入边权视为电阻，并设置 `invert_weight=True`。若传入本节的电导权重，应指定 `weight="weight", invert_weight=False`；这里的 `"weight"` 应替换为实际存放电导的边属性名。[官方参数说明](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.distance_measures.resistance_distance.html)。

### 9.5 电流介数中心性（Current-Flow Betweenness Centrality）

对每个源点 $s$ 和终点 $t$，注入与取出单位电流，求解：

```math
\mathcal L v^{(st)}=e_s-e_t.
```

其中 $e_s,e_t$ 是相应的单位基向量。边电流为：

```math
I_{ij}^{(st)}
=w_{ij}(v_i^{(st)}-v_j^{(st)}).
```

对中间节点 $i\notin\{s,t\}$：

```math
I_i^{(st)}=\frac12\sum_j|I_{ij}^{(st)}|.
```

节点原始电流介数：

```math
B_{\mathrm{CF}}(i)=
\sum_{\substack{s<t\\s,t\ne i}}I_i^{(st)}.
```

当 $n>2$ 时，可以除以 $\binom{n-1}{2}$ 归一化。它考虑多通路分流，适用于连通、无向、正电导网络，与只选择最短路径的介数不同。[3]

### 9.6 可通信性（Communicability）

简单无向无权图：

```math
e^A=
I+A+\frac{A^2}{2!}+\frac{A^3}{3!}+\cdots.
```

一种可通信性定义为：

```math
G_{ij}^{\mathrm{comm}}=(e^A)_{ij}.
```

$(A^\ell)_{ij}$ 统计长度为 $\ell$ 的游走数量，阶乘降低长游走的贡献。因此可通信性累计多种长度的连接序列。[2–3]

### 9.7 子图中心性与 Estrada 指数（Subgraph Centrality and Estrada Index）

```math
SC(i)=(e^A)_{ii}
=\sum_{\ell=0}^{\infty}\frac{(A^\ell)_{ii}}{\ell!}.
```

子图中心性累计从节点出发并返回该节点的闭合游走，不等于包含该节点的所有不同子图数量。

全图求和：

```math
EE(G)=\mathrm{tr}(e^A)
=\sum_je^{\lambda_j(A)}.
```

这称为 Estrada 指数。数学表达可以扩展到权重矩阵，但软件是否实际使用边权，需要单独检查。[24]

<a id="sec-10"></a>
## 10. 连通性、鲁棒性与流

第 10.1—10.2 节的连通度定义默认 $n\ge2$；单节点图与空图需另作约定。

### 10.1 节点连通度（Vertex Connectivity）

```math
\kappa(G)=
\min\{
|U|:G-U\text{ 不连通或只剩一个节点}
\}.
```

它表示最少删除多少节点才能破坏连通。完全图按惯例取 $n-1$，不连通图取 0。[1]

### 10.2 边连通度（Edge Connectivity）

```math
\lambda(G)=
\min\{
|F|:G-F\text{ 不连通}
\}.
```

简单无向图满足：

```math
\kappa(G)\le\lambda(G)\le\delta(G),
```

其中 $\delta(G)$ 为最小度。此处的 $\lambda(G)$ 是图参数，不是前面矩阵的特征值。[1]

### 10.3 割点与桥（Articulation Point and Bridge）

割点是删除后增加连通分量数的节点；桥是删除后增加连通分量数的边。

它们描述直接的结构脆弱位置。节点或边介数高，不保证一定是割点或桥。

### 10.4 攻击鲁棒性（Attack Robustness）

删除 $q$ 个节点后，记录：

```math
S(q)=\frac{|V_{\mathrm{LCC}}(q)|}{n}.
```

一种鲁棒性总分为：

```math
R_{\mathrm{attack}}=
\frac1n\sum_{q=1}^{n}S(q).
```

这里分母始终使用原始节点数。值越大，表示整个删除过程中保留的最大连通块总体越大。

该定义不是归一化到最大值 1 的得分。其最大值为：

```math
\frac{n-1}{2n},
```

在大网络中接近 $0.5$。

必须同时说明删除策略：随机删除、按初始度排序、每一步重新计算度，或按介数删除。同一网络不存在脱离攻击策略的唯一鲁棒性得分。[23]

### 10.5 最大流与最小容量割（Maximum Flow and Minimum Capacity Cut）

当边权表示容量 $c_{ij}$ 时，流量满足：

```math
0\le f_{ij}\le c_{ij}.
```

除源点 $s$、终点 $t$ 外，每个节点满足流量守恒：

```math
\sum_j f_{ij}=\sum_j f_{ji}.
```

最大流—最小割定理：

```math
F_{st}^{\max}=
\min_{\substack{S\subset V\\s\in S,\ t\notin S}}
\sum_{i\in S,j\notin S}c_{ij}.
```

左边是最大可运输量，右边是分开源点与终点所需切断的最小总容量。最大流考虑多路线并行运输，回答容量问题，而非距离问题。[1–3]

<a id="sec-11"></a>
## 11. 经典结构参数

本节默认简单无向图。下列参数通常通过最大化或最小化集合规模定义。[1]

### 11.1 团数（Clique Number）

```math
\omega_{\mathrm{clique}}(G)=
\max\{|S|:G[S]\text{ 为完全图}\}.
```

团内节点两两相连，团数是最大团的节点数。

极大团（Maximal Clique）表示不能继续加入节点，最大团（Maximum Clique）表示全图规模最大。极大团不一定是最大团。

### 11.2 独立数（Independence Number）

```math
\alpha_{\mathrm{ind}}(G)=
\max\{|S|:S\text{ 内没有边}\}.
```

它表示最多能选出多少个互不相邻的节点。

### 11.3 色数（Chromatic Number）

```math
\chi(G)=
\min\{
q:\exists f:V\to\{1,\ldots,q\},
\ f(i)\ne f(j)\ \forall\{i,j\}\in E
\}.
```

相邻节点必须使用不同颜色时，最少需要的颜色数。

```math
\omega_{\mathrm{clique}}(G)
\le\chi(G)\le\Delta(G)+1,
```

其中 $\Delta(G)$ 是最大度。

边色数（Chromatic Index）对边着色，要求共享端点的边不同色，可用于安排互不冲突的任务时段。

### 11.4 匹配数（Matching Number）

```math
\nu(G)=
\max\{
|M|:M\subseteq E,\ M\text{ 中的边不共享端点}
\}.
```

它表示最多能安排多少对互不冲突的配对。

最大权重匹配（Maximum-Weight Matching）把目标换成边权之和。最大权重与最多配对数量是不同目标。

### 11.5 点覆盖数（Vertex Cover Number）

```math
\tau(G)=
\min\{
|S|:\text{每条边至少有一个端点属于 }S
\}.
```

独立集的补集恰好是点覆盖，因此：

```math
\alpha_{\mathrm{ind}}(G)+\tau(G)=n.
```

二部图还满足：

```math
\nu(G)=\tau(G).
```

### 11.6 支配数（Domination Number）

```math
\gamma_{\mathrm{dom}}(G)=
\min\{
|S|:\forall v\in V,\
v\in S\ \text{或}\ N(v)\cap S\ne\varnothing
\}.
```

它表示最少选择多少节点，才能覆盖全部节点及其直接邻域。

支配集覆盖节点，点覆盖覆盖边，二者不是同一概念。带成本版本最小化所选节点的成本总和。

### 11.7 围长（Girth）

```math
g(G)=\min_{\text{环 }C}|E(C)|.
```

围长是最短环的长度。无环图通常约定为无穷。

### 11.8 环秩（Cycle Rank）

```math
\beta_{\mathrm{cycle}}(G)=m-n+c,
```

其中 $c$ 是连通分量数。它表示独立环的数量，即环空间的维数。

树满足 $m=n-1$、 $c=1$，所以环秩为 0。

<a id="sec-12"></a>
## 12. 网络熵与特殊网络

### 12.1 度分布熵（Degree Distribution Entropy）

```math
H_{\mathrm{deg}}=
-\sum_kp(k)\log p(k).
```

它描述随机抽取节点后，节点度数的不确定性。所有节点度相同的正则图，其度分布熵为 0。

仅保留度分布，因此度分布相同的不同图会得到相同结果。

### 12.2 节点度占比熵（Degree-Share Entropy）

```math
H_{\mathrm{share}}=
-\sum_iq_i\log q_i,
\qquad
q_i=\frac{k_i}{2m},
\qquad m>0.
```

它描述边端点在节点间的分配是否均匀。非空正则图达到固定 $n$ 下的最大值 $\log n$。

同一正则图在度分布熵下为 0，在度占比熵下最大，原因是两者使用不同的概率分布。

### 12.3 冯诺依曼网络熵（Von Neumann Network Entropy）

一种定义使用：

```math
\varrho=
\frac{\mathcal L}{\mathrm{tr}\mathcal L}.
```

令 $\eta_i$ 是 $\varrho$ 的特征值：

```math
H_{\mathrm{VN}}=
-\mathrm{tr}(\varrho\log\varrho)
=-\sum_i\eta_i\log\eta_i.
```

要求无向非负权重，且拉普拉斯迹大于零。约定 $0\log0=0$。

另有使用归一化拉普拉斯或热核构造概率谱的定义，不能混作同一个指标。对数底决定单位，例如底为 2 时以比特计。

不能统一声称“网络熵越大，网络越复杂或越好”。[27]

### 12.4 二部图密度与二部模块度（Bipartite Density and Bipartite Modularity）

二部图节点分成 $U,V$ 两组，边只允许跨组连接。若两组大小为 $n_U,n_V$，且 $n_U>0,n_V>0$：

```math
\rho_{\mathrm{bip}}=
\frac{m}{n_Un_V}.
```

二部图没有三角形，因此普通三角聚类不能描述其主要局部组织，应考虑四环或专用二部聚类。

设 $B_{uv}$ 是跨组邻接矩阵， $k_u,d_v$ 是两组节点的度，当 $m>0$ 时，一种二部模块度为：

```math
Q_{\mathrm{bip}}=
\frac1m
\sum_{u\in U,v\in V}
\left(
B_{uv}-\frac{k_ud_v}{m}
\right)
\delta(c_u,c_v).
```

分母为 $m$，不是 $2m$。将二部图投影成普通图，会改变度、密度和聚类等指标。[25]

### 12.5 时间可达率与时间距离（Temporal Reachability and Temporal Distance）

时间网络的路径必须满足接触发生的先后顺序。给定起点时间 $t_0$ 和观察窗口：

```math
R_{\mathrm{temp}}(t_0)=
\frac1{n(n-1)}
\sum_{i\ne j}
\mathbf1\{
i\text{ 可沿时间有序路径到达 }j
\}.
```

时间距离可分为最早到达时间（Earliest Arrival Time）、最快路径持续时间（Fastest-Path Duration）和最少跳数（Minimum Hop Count）。

需要说明能否等待、同时接触能否连续使用、观察窗口和起点时间。静态合并图中的通路，可能在实际时间顺序中无法走通。[26]

### 12.6 三角形平衡率与挫折指数（Triangle Balance Ratio and Frustration Index）

有符号网络中，边符号 $\epsilon_{ij}\in\{-1,1\}$ 分别表示两类相反关系。

三角形层面的强结构平衡率：

```math
B_\triangle=
\frac{
\#\{\text{边符号乘积为正的三角形}\}
}{
\#\{\text{全部三角形}\}
}.
```

正正正、正负负属于强结构平衡中的平衡三角形。没有三角形时原式无定义。

全局挫折指数：

```math
\ell_{\mathrm{frust}}(G)=
\min_{x_i\in\{-1,1\}}
\sum_{\{i,j\}\in E}
\frac{1-\epsilon_{ij}x_ix_j}{2}.
```

它寻找两组划分，使组内负边与组间正边的总数最少；也等于使图达到强结构平衡所需删除的最少边数。

一般图中，所有三角形平衡不足以证明全图平衡。全图强结构平衡要求每个环的符号乘积为正。例如只有一个负边的四节点环，没有三角形，但仍不平衡。[28]

C_C(B)=\frac3{1+1+2}=\frac34.

B_N(B)=\frac{1+1+0}{3}=\frac23.

```math
Q=2\left(\frac13-\frac14\right)=\frac16.
```

### 13.2 两个三角形加一条桥

~~~mermaid
graph LR
    subgraph S1["社区 1"]
        A --- B
        B --- C
        C --- A
    end
    subgraph S2["社区 2"]
        D --- E

    C --- D
~~~

节点度为：

```math
(2,2,3,3,2,2),
\qquad m=7.
```

固定社区为：

```math
S_1=\{A,B,C\},\qquad S_2=\{D,E,F\}.
```

#### 13.2.1 富人俱乐部计算

| 阈值 | 成员 | 原始系数 |
|---|---|---:|
| $k=0$ 或 $k=1$ | 全部六节点 | $7/15$ |
| $k=2$ | C、D | $1$ |
| $k\ge3$ | 无成员 | 无定义 |

富节点 C、D 属于不同社区，说明富人俱乐部与社区不是同一种节点集合。

对保持每个节点上述度数的带标签简单图，本次有限枚举得到 54 张合法图，其中 42 张存在 CD，且 54 张均连通。

若这 54 张图等概率作为参照：

```math
\mathbb E_{\mathrm{null}}[\phi(2)]
=\frac{42}{54}=\frac79,
```

```math
\phi_{\mathrm{norm}}(2)=\frac1{7/9}=\frac97.
```

但参照中达到不低于实际值的比例仍为：

```math
\Pr_{\mathrm{null}}\{\phi(2)\ge1\}=\frac79.
```

这是本例指定参照模型下的精确单侧概率，说明归一化大于 1 不自动表示显著。

#### 13.2.2 模块度计算

每个三角形社区的内部边数为 3，总度为 7：

```math
Q_\gamma=
2\left[
\frac37-\gamma\left(\frac7{14}\right)^2
\right]
=\frac67-\frac\gamma2.
```

$\gamma=1$ 时：

```math
Q=\frac5{14}\approx0.3571.
```

| 划分方式 | 标准模块度 |
|---|---:|
| 全部节点在一个社区 | $0$ |
| 两三角形各成社区 | $5/14$ |
| $\{A,B\},\{C,D\},\{E,F\}$ | $4/49$ |
| 每节点单独成社区 | $-17/98$ |

#### 13.2.3 参与系数计算

A、B、E、F 的连接全部在各自社区，因此参与系数为 0。

C、D 各有两条社区内连接和一条社区外连接：

```math
P_C=P_D=
1-\left(\frac23\right)^2-\left(\frac13\right)^2
=\frac49.
```

若全图改为一个社区，所有参与系数变为 0；若每个节点单独成社区，C、D 变为 $2/3$，其余节点变为 $1/2$。这些变化完全来自划分，而非边的改变。

### 13.3 改变桥权重后的联合解释

保持六条三角形内部边权均为 1，桥 CD 的权重为 $x>0$。保持上述两个社区划分，并按度大于 2 选择 C、D。

原始无权富人俱乐部系数始终为 1。原始加权富人俱乐部系数：

```math
\phi^w(2)=\frac{x}{\max(1,x)}.
```

固定划分的加权模块度：

```math
Q^w=\frac6{6+x}-\frac12.
```

C、D 的加权参与系数：

```math
P_C^w=P_D^w=
1-\left(\frac2{2+x}\right)^2
-\left(\frac{x}{2+x}\right)^2
=\frac{4x}{(2+x)^2}.
```

| 桥权重 $x$ | 原始加权富人俱乐部系数 | 固定划分的加权模块度 | C、D 的加权参与系数 |
|---:|---:|---:|---:|
| $0.2$ | $0.2$ | 约 $0.468$ | 约 $0.165$ |
| $1$ | $1$ | 约 $0.357$ | $4/9$ |
| $2$ | $1$ | $0.250$ | $1/2$ |
| $4$ | $1$ | $0.100$ | $4/9$ |

解释：

- 富人俱乐部系数关注高度节点之间是否相连，以及其已有连接是否强。
- 桥越强，原有两个社区的内部集中程度相对下降，所以固定划分的模块度下降。
- 内部总强度为 2，桥权为 2 时，内外强度各占一半，参与系数最高。桥继续增强，连接又集中到另一社区，所以参与系数下降。

参与系数衡量分散程度，不会随着外部连接强度一直增加。表中的加权富人俱乐部值也只是原始值，尚不能替代随机参照检验。

## 14. 指标选择与结果报告

### 14.1 按研究问题选择

| 研究问题 | 优先指标 |
|---|---|
| 网络有多大、连接多密？ | 节点数、边数、密度、平均度 |
| 连接是否集中于少数节点？ | 度分布、度方差、网络中心化 |
| 哪些节点直接联系多？ | 度、强度、入度、出度 |
| 哪些节点平均到达其他节点更方便？ | 接近中心性、调和中心性 |
| 哪些节点或边承接较多通路？ | 节点介数、边介数、电流介数 |
| 局部关系是否闭合、是否有替代路线？ | 局部聚类、传递性、局部效率 |
| 高度节点之间是否比参照更紧密？ | 原始与归一化富人俱乐部曲线 |
| 社区划分是否体现内部连接超额？ | 模块度、导通率、归一化割 |
| 节点联系是否分布在多个社区？ | 参与系数，结合度、强度和社区内度标准分 |
| 网络哪里容易断开？ | 桥、割点、节点连通度、边连通度 |
| 连续删除节点后保留多少连接？ | 最大连通分量曲线、攻击鲁棒性 |
| 网络能运输多少流量？ | 最大流、最小容量割 |
| 如何安排互不冲突的配对和资源？ | 匹配数、色数、点覆盖数、支配数 |

### 14.2 三个易混淆指标的对照

| 比较项 | 富人俱乐部系数（Rich-Club Coefficient） | 模块度（Modularity） | 参与系数（Participation Coefficient） |
|---|---|---|---|
| 评价对象 | 阈值选出的节点子图 | 整个社区划分 | 单个节点 |
| 核心问题 | 富节点彼此连接是否紧密 | 内部连接是否超出基准 | 联系是否分散到不同社区 |
| 是否需要社区划分 | 不需要 | 需要待评价划分 | 需要固定划分 |
| 常见输出 | 随阈值变化的曲线 | 每个划分一个分数 | 每个节点一个分数 |
| 主要依赖 | 成员筛选、阈值、参照模型 | 划分、参照模型、分辨率 | 划分、社区数量与大小、节点度 |
| 常见误解 | 原始值高就有显著效应 | 高分就证明实际社区正确 | 高分就是外部连接多或影响力大 |

### 14.3 报告结果需要说明的条件

1. 图类型：有向或无向、是否允许自环和重复边。
2. 建图规则：边由什么数据产生，阈值或稀疏度如何选择。
3. 权重含义：强度、距离、容量还是符号。
4. 具体公式与归一化：尤其是介数、聚类、富人俱乐部和熵。
5. 不可达节点与零分母的处理。
6. 社区划分的算法、目标函数、分辨率与稳定性。
7. 随机参照保留的条件、样本数与显著性检验办法。
8. 比较网络的规模、密度、权重单位是否一致。
9. 软件和版本；算法实现与数学定义可能存在差异。

指标的解释应与数据含义和研究问题一致。拓扑位置本身不能替代对实际流量、功能或因果作用的验证。
