# 常见机器学习算法：从核心逻辑到数学形式的系统理解

## 1. 机器学习到底在做什么？

机器学习最核心的问题可以写成：

```math
X \longrightarrow f \longrightarrow Y
```

其中：

- \(X\)：输入特征；
- \(Y\)：我们希望预测、解释或区分的目标；
- \(f\)：机器学习算法希望从数据中学习出来的映射关系。

如果有 \(n\) 个样本、每个样本有 \(p\) 个特征，那么通常写成：

```math
X=
\begin{bmatrix}
x_{11} & x_{12} & \cdots & x_{1p}\\
x_{21} & x_{22} & \cdots & x_{2p}\\
\vdots & \vdots & & \vdots\\
x_{n1} & x_{n2} & \cdots & x_{np}
\end{bmatrix}
```

其中：

- 第 \(i\) 行：第 \(i\) 个样本；
- 第 \(j\) 列：第 \(j\) 个特征。

如果是监督学习，还有目标变量：

```math
Y=
\begin{bmatrix}
y_1\\
y_2\\
\vdots\\
y_n
\end{bmatrix}
```

机器学习算法之间真正的区别，不是“谁更高级”，而是：

> 它们对 \(X\rightarrow Y\) 的关系采用了不同的表示方式、优化目标和假设。

---

# 2. 监督学习与无监督学习

## 2.1 监督学习

监督学习有明确的目标 \(Y\)。

例如：

```math
\text{脑影像特征} \rightarrow \text{认知得分}
```

或者：

```math
\text{功能连接} \rightarrow \text{抑郁 / 健康}
```

如果 \(Y\) 是连续值，例如年龄、认知得分、症状评分，就是回归。

如果 \(Y\) 是类别，例如健康/疾病，就是分类。

---

## 2.2 无监督学习

无监督学习只有：

```math
X
```

没有目标 \(Y\)。

它问的是：

> 数据本身有没有某种结构？

例如：

- 样本是否自然分成几类；
- 1000个变量是否可以压缩为几个主要维度；
- 哪些变量彼此高度相关。

常见算法包括：

- K-means；
- 层次聚类；
- PCA；
- ICA；
- Autoencoder。

---

# 3. 线性回归 Linear Regression

线性回归是理解机器学习最好的起点。

假设有两个特征：

```math
X_1,\quad X_2
```

线性回归假设：

```math
Y=\beta_0+\beta_1X_1+\beta_2X_2+\epsilon
```

其中：

- \(\beta_0\)：截距；
- \(\beta_1,\beta_2\)：每个特征的权重；
- \(\epsilon\)：模型无法解释的误差。

预测值是：

```math
\hat{Y}=\beta_0+\beta_1X_1+\beta_2X_2
```

对第 \(i\) 个样本：

```math
\hat y_i=\beta_0+\beta_1x_{i1}+\beta_2x_{i2}
```

误差：

```math
e_i=y_i-\hat y_i
```

普通最小二乘法 OLS 的目标是：

```math
\min_{\beta}
\sum_{i=1}^{n}
(y_i-\hat y_i)^2
```

也就是让所有预测误差的平方和最小。

---

## 3.1 为什么是平方误差？

如果简单求：

```math
\sum(y_i-\hat y_i)
```

正误差和负误差可能相互抵消。

平方以后：

```math
(y_i-\hat y_i)^2
```

所有误差都变成正数，同时大误差会被更强地惩罚。

因此：

```math
\text{SSE}
=
\sum_i(y_i-\hat y_i)^2
```

成为最常用的回归损失之一。

---

## 3.2 线性到底是什么意思？

线性不是说数据图像一定是一条直线，而是说：

```math
Y
```

对参数 \(\beta\) 是线性的。

例如：

```math
Y=
\beta_0+\beta_1X+\beta_2X^2
```

从 \(X\) 的角度看，它是曲线。

但对参数：

```math
\beta_0,\beta_1,\beta_2
```

仍然是线性的。

因此它仍然属于线性模型。

---

## 3.3 线性回归的优点

- 可解释性强；
- 参数意义明确；
- 计算快；
- 很适合做统计推断；
- 是理解很多更复杂算法的基础。

---

## 3.4 局限

如果真正关系明显非线性：

```math
Y=f(X)
```

而 \(f\) 很复杂，那么简单线性模型可能无法捕捉。

这会导致：

```math
\text{underfitting}
```

即欠拟合。

---

# 4. Ridge 回归：给模型加一个“不要太激进”的约束

普通线性回归只最小化：

```math
\sum_i(y_i-\hat y_i)^2
```

Ridge 加入惩罚项：

```math
\min_{\beta}
\left[
\sum_i(y_i-\hat y_i)^2
+
\lambda\sum_j\beta_j^2
\right]
```

其中：

```math
\lambda \ge 0
```

控制正则化强度。

---

## 4.1 Ridge 到底在解决什么问题？

假设：

```math
X_1\approx X_2
```

两个变量高度相关。

OLS 可能得到：

```math
\beta_1=20,\qquad
\beta_2=-19
```

两者相互抵消以后仍然可以预测得不错。

但这种参数非常不稳定。

稍微更换一批数据，可能变成：

```math
\beta_1=-10,\qquad
\beta_2=11
```

Ridge 会惩罚大系数：

```math
\beta_j^2
```

因此更倾向于得到：

```math
\beta_1=0.5,\qquad
\beta_2=0.4
```

也就是：

> 不允许模型过分依赖某一个特征。

---

## 4.2 为什么 Ridge 适合相关特征？

当两个特征包含类似信息时，Ridge倾向于让它们共同分担预测权重，而不是极端地选择其中一个。

因此对于：

- 脑连接；
- 基因表达；
- 高维影像特征；

这种变量之间高度相关的数据，Ridge很常见。

---

## 4.3 \(\lambda\) 的意义

当：

```math
\lambda=0
```

Ridge 就退化为普通线性回归。

当：

```math
\lambda\rightarrow\infty
```

系数会越来越接近0。

所以：

```math
\lambda
```

控制的是：

```math
\text{拟合数据}
\quad\leftrightarrow\quad
\text{模型简单稳定}
```

之间的权衡。

---

# 5. LASSO：既做预测，又做特征选择

LASSO 的目标函数是：

```math
\min_{\beta}
\left[
\sum_i(y_i-\hat y_i)^2
+
\lambda\sum_j|\beta_j|
\right]
```

Ridge 使用：

```math
\beta_j^2
```

LASSO 使用：

```math
|\beta_j|
```

这一点看似很小，但结果非常不同。

---

## 5.1 LASSO 为什么能把系数压到0？

L1 惩罚：

```math
|\beta_j|
```

在0处存在尖角。

从几何和优化角度，这会使最优解更容易恰好落在：

```math
\beta_j=0
```

因此，LASSO自然产生稀疏模型。

例如原来有：

```math
1000
```

个变量，最终可能只剩下：

```math
30
```

个非零系数。

因此：

```math
\boxed{\text{LASSO = 预测 + 特征选择}}
```

---

## 5.2 Ridge 与 LASSO 的本质区别

Ridge：

> 大家都可以留下，但不要太大。

LASSO：

> 有些变量干脆不要。

---

## 5.3 Elastic Net

Elastic Net 同时结合：

```math
L1 + L2
```

即：

```math
\text{Loss}
+
\lambda_1\sum|\beta_j|
+
\lambda_2\sum\beta_j^2
```

它希望同时获得：

- Ridge 的稳定性；
- LASSO 的稀疏性。

在高度相关的高维数据中非常常见。

---

# 6. Logistic Regression：把线性模型变成分类模型

假设目标变量：

```math
Y\in\{0,1\}
```

例如：

```math
0=\text{健康},\qquad
1=\text{疾病}
```

如果直接使用线性模型：

```math
\hat Y=\beta_0+\beta_1X_1+\cdots
```

可能得到：

```math
1.8
```

但概率必须在：

```math
0\sim1
```

之间。

因此 Logistic Regression 先计算：

```math
z=\beta_0+\beta_1X_1+\cdots+\beta_pX_p
```

再通过 Sigmoid：

```math
p=
\frac{1}{1+e^{-z}}
```

得到：

```math
0<p<1
```

---

## 6.1 Logistic Regression 真正建模的是什么？

它实际上建模的是 log odds：

```math
\log
\frac{p}{1-p}
=
\beta_0+\beta_1X_1+\cdots+\beta_pX_p
```

其中：

```math
\frac{p}{1-p}
```

叫做 odds。

因此：

```math
e^{\beta_j}
```

在其他特征保持不变时，可以解释为该特征增加 1 个单位后 odds 的倍数变化；如果特征经过标准化，单位应理解为 1 个标准差。

---

## 6.2 Logistic Regression 的损失函数

分类任务不能直接用普通平方误差作为最自然的目标。

二分类 Logistic Regression 通常最小化交叉熵：

```math
L=
-\sum_i
\left[
y_i\log p_i
+
(1-y_i)\log(1-p_i)
\right]
```

如果真实：

```math
y_i=1
```

但模型给：

```math
p_i=0.01
```

损失会非常大。

因此：

> 模型如果非常自信地预测错，会受到很强惩罚。

---

# 7. K-Nearest Neighbors：局部相似性学习

KNN的核心思想是：

> 和我最相似的样本，通常应该具有相似的结果。

对于新样本：

```math
x_{\text{new}}
```

计算它和训练集中所有样本的距离。

最常见的是欧氏距离：

```math
d(x_i,x_j)
=
\sqrt{
\sum_k(x_{ik}-x_{jk})^2
}
```

然后找最近的：

```math
K
```

个邻居。

---

## 7.1 分类

例如 \(K=5\)。

最近5个样本：

- 疾病；
- 疾病；
- 健康；
- 疾病；
- 健康。

则多数为疾病。

因此预测疾病。

---

## 7.2 回归

KNN也可以做回归。

例如最近5个样本的认知得分：

```math
80,82,77,79,84
```

可以取平均：

```math
\hat y=80.4
```

作为预测。

---

## 7.3 为什么标准化很重要？

假设：

```math
X_1=\text{年龄}=20\sim80
```

```math
X_2=\text{脑区体积}=1000\sim10000
```

因为脑区体积数值范围大得多，它会主导距离计算。

因此KNN通常需要：

```math
z=
\frac{x-\mu}{\sigma}
```

进行标准化。

---

## 7.4 K 的影响

如果：

```math
K=1
```

模型极度依赖最近样本，容易对噪声敏感。

如果：

```math
K
```

非常大，模型又会过度平滑。

因此KNN也存在：

```math
\text{bias-variance tradeoff}
```

---

# 8. Decision Tree：通过条件不断切分特征空间

决策树的预测方式类似：

```text
X1 > 0.5 ?
├── Yes → X3 < 1.2 ?
│          ├── Yes → Class A
│          └── No  → Class B
└── No  → Class A
```

每个节点对应一次：

```math
X_j<t
```

的判断。

---

## 8.1 树到底在优化什么？

树希望每次切分以后，子节点中的类别更加纯。

例如一个节点里：

```math
50\text{ 健康}
+
50\text{ 疾病}
```

非常混杂。

如果切分后：

左节点：

```math
45\text{ 健康}+5\text{ 疾病}
```

右节点：

```math
5\text{ 健康}+45\text{ 疾病}
```

就说明这个切分很好。

---

## 8.2 Gini impurity

二分类时：

```math
Gini
=
1-p_1^2-p_2^2
```

如果：

```math
p_1=1,\quad p_2=0
```

那么：

```math
Gini=0
```

表示完全纯。

如果：

```math
p_1=p_2=0.5
```

则不纯度较高。

树会寻找：

> 能最大程度降低不纯度的特征和阈值。

---

## 8.3 决策树的优点

- 很直观；
- 能自动学习非线性；
- 可以自动表示变量交互；
- 不需要变量满足线性关系。

---

## 8.4 最大问题：高方差

一棵树非常容易受到训练数据扰动影响。

稍微换一些样本，树结构可能完全改变。

这就是：

```math
\text{high variance}
```

也是Random Forest出现的原因。

---

# 9. Random Forest：通过“很多不同的树”降低方差

Random Forest训练很多棵树：

```math
T_1,T_2,\ldots,T_B
```

然后将它们组合。

分类：

```math
\hat y=
\text{majority vote}
```

回归：

```math
\hat y=
\frac{1}{B}\sum_{b=1}^{B}T_b(x)
```

---

## 9.1 为什么树之间要有差异？

如果500棵树完全一样，那么投票没有意义。

所以随机森林通过两种随机性让树彼此不同。

### Bootstrap sampling

从训练集有放回抽样。

每棵树看到不同的样本。

### Random feature subset

每个节点分裂时，不允许查看所有特征。

而是随机抽部分特征进行候选。

这样可以降低不同树之间的相关性。

---

## 9.2 Random Forest 的核心逻辑

单棵树：

```math
\text{低 bias，高 variance}
```

很多不完全相同的树取平均：

```math
\text{variance下降}
```

而又保留树的非线性表达能力。

这就是：

```math
\boxed{\text{Bagging}}
```

的核心思想。

---

# 10. Boosting：后一轮专门修正前面的错误

Boosting和Random Forest完全不同。

Random Forest：

> 多棵树相对独立训练。

Boosting：

> 树是按顺序训练的。

第一个模型：

```math
f_1(x)
```

预测后得到误差。

第二个模型：

```math
f_2(x)
```

重点学习前一个模型没有解释好的部分。

最终：

```math
F(x)=
f_1(x)+f_2(x)+\cdots+f_M(x)
```

---

# 11. Gradient Boosting：沿损失下降方向逐步加模型

假设当前模型：

```math
F_m(x)
```

损失：

```math
L(y,F_m(x))
```

Gradient Boosting希望加入新模型：

```math
h_m(x)
```

使：

```math
F_{m+1}(x)
=
F_m(x)+\eta h_m(x)
```

其中：

```math
\eta
```

是 learning rate。

---

## 11.1 为什么说它是“梯度”Boosting？

它不是简单地学习：

```math
y-\hat y
```

在一般损失函数下，它学习的是：

```math
-\frac{\partial L}{\partial F}
```

也就是：

> 当前损失函数下降最快的方向。

对于平方误差：

```math
L=(y-\hat y)^2
```

负梯度正好和残差高度相关。

所以在平方误差情况下，可以直观理解为：

> 新树不断学习上一轮剩下的残差。

---

# 12. XGBoost、LightGBM、CatBoost

它们都属于Gradient Boosting家族。

## XGBoost

主要特点：

- 正则化；
- 二阶梯度信息；
- 处理缺失值；
- 高效并行实现。

## LightGBM

特点：

- 对大规模数据非常快；
- 使用 histogram；
- 常采用 leaf-wise growth。

## CatBoost

特别适合：

- 类别型变量；
- 通过有序统计等方法减少类别编码导致的目标泄漏。

它们的根本思想仍然是：

```math
\boxed{\text{逐步增加弱学习器来修正当前模型}}
```

---

# 13. Support Vector Machine：寻找最大间隔分类边界

考虑二维二分类问题。

希望找到：

```math
w^Tx+b=0
```

把两类分开。

很多不同的直线都可能做到。

SVM不是随便找一条，而是希望：

> 离两类最近样本都尽可能远。

---

## 13.1 Margin

决策边界：

```math
w^Tx+b=0
```

两条间隔边界：

```math
w^Tx+b=1
```

和：

```math
w^Tx+b=-1
```

它们之间距离是：

```math
\frac{2}{\|w\|}
```

最大化间隔相当于最小化：

```math
\frac12\|w\|^2
```

---

## 13.2 Support Vectors

并不是所有样本都决定最终分界面。

真正重要的是最靠近边界的样本。

这些样本叫：

```math
\boxed{\text{support vectors}}
```

所以“支持向量机”的名字来自这里。

---

## 13.3 Soft Margin

真实数据通常不可能完全分开。

因此允许某些样本违反间隔：

```math
\xi_i\ge0
```

优化：

```math
\min
\frac12\|w\|^2
+
C\sum_i\xi_i
```

同时满足软间隔约束：

```math
y_i(w^\top x_i+b)\ge1-\xi_i
```

其中：

```math
C
```

控制：

```math
\text{宽间隔}
\quad\leftrightarrow\quad
\text{少犯分类错误}
```

---

# 14. Kernel SVM：把非线性问题转成高维线性问题

如果二维空间里两类数据呈环状：

```text
OOOOOO
O XXXX O
O XXXX O
OOOOOO
```

一条直线无法分开。

一个办法是增加高维特征，例如：

```math
x_1^2,\quad
x_2^2,\quad
x_1x_2
```

映射：

```math
\phi(x)
```

在更高维空间中，可能就能线性分离。

---

## 14.1 Kernel Trick

SVM很多计算只依赖内积：

```math
\phi(x_i)^T\phi(x_j)
```

Kernel允许直接计算：

```math
K(x_i,x_j)
```

而不需要显式构造：

```math
\phi(x)
```

最常见的RBF Kernel：

```math
K(x_i,x_j)
=
\exp
\left(
-\gamma
\|x_i-x_j\|^2
\right)
```

因此可以学习非常复杂的非线性边界。

---

# 15. Naive Bayes：从生成概率反推类别

Bayes公式：

```math
P(Y|X)
=
\frac{P(X|Y)P(Y)}{P(X)}
```

分类时关心：

```math
P(Y=k|X)
```

因为：

```math
P(X)
```

对不同类别相同，所以只需要比较：

```math
P(X|Y=k)P(Y=k)
```

---

## 15.1 Naive 假设

如果：

```math
X=(X_1,X_2,\ldots,X_p)
```

Naive Bayes假设给定类别后：

```math
X_1,X_2,\ldots,X_p
```

相互条件独立。

因此：

```math
P(X|Y)
=
\prod_{j=1}^{p}
P(X_j|Y)
```

这里：

```math
\prod_j
```

就是对不同 \(j\) 连续相乘。

例如：

```math
\prod_{j=1}^{3}a_j
=
a_1a_2a_3
```

---

## 15.2 为什么“朴素”假设这么强还可以工作？

现实中特征往往不是完全独立。

但分类并不一定要求概率模型完全正确。

只要不同类别之间：

```math
P(X|Y=k)
```

能够形成足够明显的相对差异，分类仍然可能不错。

---

# 16. 神经网络：多层非线性函数组合

单个神经元可以写成：

```math
z=w^Tx+b
```

然后经过激活函数：

```math
a=g(z)
```

例如ReLU：

```math
g(z)=\max(0,z)
```

---

## 16.1 为什么需要激活函数？

如果每层都只是线性变换：

```math
h_1=W_1x
```

```math
h_2=W_2h_1
```

则：

```math
h_2=W_2W_1x
```

仍然只是一个线性变换。

无论叠多少层，本质仍然是：

```math
Wx
```

所以：

> 非线性激活函数才让深层网络真正具有更复杂的表达能力。

---

## 16.2 多层网络

例如：

```math
h^{(1)}
=
g(W_1x+b_1)
```

```math
h^{(2)}
=
g(W_2h^{(1)}+b_2)
```

```math
\hat y=
W_3h^{(2)}+b_3
```

整体就是：

```math
\hat y=
f_3(f_2(f_1(x)))
```

---

# 17. 神经网络是如何训练的？

首先定义损失函数：

```math
L(\theta)
```

其中：

```math
\theta
```

代表所有网络权重。

目标：

```math
\min_\theta L(\theta)
```

通过梯度下降：

```math
\theta_{new}
=
\theta_{old}
-
\eta
\frac{\partial L}{\partial\theta}
```

其中：

```math
\eta
```

叫 learning rate。

---

## 17.1 Backpropagation

神经网络参数可能有百万甚至数十亿。

需要计算：

```math
\frac{\partial L}{\partial w_j}
```

反向传播利用链式法则：

```math
\frac{\partial L}{\partial w}
=
\frac{\partial L}{\partial h_3}
\frac{\partial h_3}{\partial h_2}
\frac{\partial h_2}{\partial h_1}
\frac{\partial h_1}{\partial w}
```

从输出层逐层向前计算梯度。

---

# 18. K-means：寻找数据中的聚类中心

假设认为数据存在：

```math
K
```

个自然群体。

定义每个cluster的中心：

```math
\mu_1,\mu_2,\ldots,\mu_K
```

目标：

```math
\min
\sum_{k=1}^{K}
\sum_{i\in C_k}
\|x_i-\mu_k\|^2
```

即：

> 每个样本尽量靠近自己所属cluster的中心。

---

## 18.1 K-means 的迭代过程

### 第一步：随机初始化中心

```math
\mu_1,\ldots,\mu_K
```

### 第二步：Assignment

每个样本分给距离最近的中心。

### 第三步：Update

重新计算：

```math
\mu_k=
\frac{1}{|C_k|}
\sum_{i\in C_k}x_i
```

### 第四步

重复直到中心基本不再变化。

---

## 18.2 K-means 的假设

它比较适合：

- 类似球形的cluster；
- 大小相近；
- 密度相近。

如果cluster是月牙形、长条形，K-means可能效果不好。

---

# 19. Hierarchical Clustering：建立层级关系

层次聚类通常不直接给出唯一的K类。

它首先把每个样本当成一个cluster。

然后：

> 每次合并最接近的两个cluster。

直到最后所有样本都合成一类。

得到：

```math
\text{dendrogram}
```

---

## 19.1 什么叫两个cluster“接近”？

这取决于 linkage。

### Single linkage

```math
d(A,B)
=
\min_{i\in A,j\in B}
d(i,j)
```

看最近的两个点。

### Complete linkage

```math
d(A,B)
=
\max_{i\in A,j\in B}
d(i,j)
```

看最远的一对点。

### Average linkage

计算两个cluster所有跨组距离的平均值。

### Ward linkage

选择：

> 合并后使组内平方和增加最少的两个cluster。

# 20. PCA：寻找数据方差最大的方向

PCA不是分类算法。

它解决：

```math
\text{高维数据}
\rightarrow
\text{低维表示}
```

---

## 20.1 第一主成分

标准 PCA 通常先对特征进行中心化；如果各特征量纲差异很大，是否进一步标准化也会影响主成分结果。

希望找到向量：

```math
w
```

将数据投影为：

```math
z=Xw
```

使：

```math
Var(z)
```

最大。

即：

```math
\max_w Var(Xw)
```

约束：

```math
\|w\|=1
```

---

## 20.2 为什么最大方差方向有意义？

如果一个方向上几乎没有变化，那么这个方向携带的数据差异很少。

如果一个方向上变化很大，那么：

> 样本之间的主要差异可能就集中在这个方向。

所以PCA优先保留方差最大的方向。

---

## 20.3 第二主成分

第二个方向：

```math
w_2
```

必须与第一主成分正交：

```math
w_1^Tw_2=0
```

同时在剩余空间里解释尽可能多的方差。

---

## 20.4 PCA 与特征选择不同

特征选择：

> 从原变量中挑一些。

PCA：

> 把原变量重新组合成新的变量。

例如：

```math
PC_1
=
0.4X_1
+
0.3X_2
-
0.2X_3
+\cdots
```

因此PCA是：

```math
\boxed{\text{feature extraction}}
```

不是简单的：

```math
\boxed{\text{feature selection}}
```

---

# 21. Bias–Variance Tradeoff

机器学习最重要的思想之一。

假设真实关系：

```math
Y=f(X)+\epsilon
```

预测误差可以概念性拆成：

```math
\text{Prediction Error}
\approx
\text{Bias}^2
+
\text{Variance}
+
\text{Irreducible Noise}
```

这是平方损失下对期望预测误差的概念性分解；不同损失函数下不能直接套用这条形式。

---

## 21.1 Bias

模型本身太简单，无法表达真实关系。

例如真实是曲线，但模型只能拟合直线。

这叫：

```math
\text{high bias}
```

表现为欠拟合。

---

## 21.2 Variance

模型对训练数据非常敏感。

稍微更换训练集，结果大幅变化。

这叫：

```math
\text{high variance}
```

表现为过拟合。

---

## 21.3 不同算法的直觉位置

一般而言：

- Linear Regression：在模型设定简单且正确时通常偏高 bias、低 variance；
- 深决策树：通常低 bias、高 variance；
- Random Forest：通过平均降低variance；
- Ridge：主动增加一点bias换取variance下降；
- 神经网络：表达能力强，通常需要通过正则化、早停或验证集等方式控制过拟合。

---

# 22. Overfitting 与 Generalization

训练集上表现好，不代表模型真正好。

假设：

```math
Accuracy_{train}=100\%
```

但：

```math
Accuracy_{test}=60\%
```

说明模型可能只是记住了训练数据。

机器学习真正关心：

```math
\boxed{\text{Generalization}}
```

即：

> 对从未见过的数据是否仍然有效。

---

# 23. Train / Validation / Test

通常把数据分为：

## Training set

用于学习参数：

```math
\beta,\quad w,\quad tree,\quad neural\ network\ weights
```

## Validation set

用于选择超参数，例如：

```math
\lambda,\quad K,\quad C,\quad depth,\quad learning\ rate
```

## Test set

只在最后评估一次。

它模拟：

> 真正未知的新数据。

---

# 24. 参数和超参数的区别

## 参数 Parameter

从数据中直接学习。

例如：

线性回归：

```math
\beta
```

神经网络：

```math
W,b
```

决策树：

- 训练得到的树结构、分裂特征和分裂阈值。

---

## 超参数 Hyperparameter

训练前或通过验证过程选择。

例如：

Ridge：

```math
\lambda
```

KNN：

```math
K
```

Random Forest：

```math
n_{\text{trees}}
```

SVM：

```math
C,\gamma
```

神经网络：

- learning rate；
- layer number；
- hidden units；
- dropout。

---

# 25. Cross-validation

如果样本数有限，单次Train/Validation切分可能不稳定。

K-fold cross-validation 将数据分为：

```math
K
```

份。

例如：

```math
K=5
```

每次：

- 4份训练；
- 1份验证。

轮流5次。

最终平均性能。

这样可以更稳定地评估超参数。

---

# 26. 数据泄漏 Data Leakage

机器学习研究中一个极其重要的问题。

如果测试集信息以任何方式参与了模型训练，测试性能会被高估。

例如：

先在全部数据上做：

```math
\text{feature selection}
```

再划分训练集和测试集。

这是泄漏。

正确做法应该是：

```math
\text{training data}
\rightarrow
\text{feature selection}
\rightarrow
\text{model}
```

然后把训练阶段得到的选择规则应用到测试集。

类似地：

- 标准化；
- PCA；
- 缺失值填补；
- 特征选择；
- 超参数优化；

原则上都应在训练数据内部完成。

在交叉验证中，这些步骤也应在每个训练折内拟合，再应用到对应的验证折。

# 29. 在神经科学数据中的典型场景

假设：

```math
X=
\text{20,000条功能连接}
```

目标：

```math
Y=
\text{抑郁 / 健康}
```

不同算法的理解方式如下。

## Logistic Regression

```math
P(\text{MDD})
=
\sigma
\left(
\beta_0+
\sum_j\beta_jFC_j
\right)
```

重点是：

> 每条连接以线性加权方式共同决定分类概率。

---

## Ridge

所有连接可以参与，但整体收缩权重。

适合：

```math
p\gg n
```

且特征高度相关的情况。

---

## LASSO

希望从大量连接中筛出一部分预测连接。

---

## SVM

在高维连接空间中寻找分隔健康和疾病样本的最大间隔超平面。

---

## Random Forest

通过大量连接阈值不断切分样本，并让多棵树投票。

---

## XGBoost

让一系列树逐步修正已有分类错误。

---

## Neural Network

允许不同连接之间形成复杂非线性组合。

---

## PCA + classifier

先：

```math
20,000D
\rightarrow
50D
```

再使用：

- Logistic；
- SVM；
- Ridge；

进行分类。

---

# 30. 学习一个新算法时，建议固定问这几个问题

以后遇到任何新的机器学习算法，可以按下面顺序理解。

### 1. 它解决什么问题？

分类、回归、聚类还是降维？

### 2. 输入和输出是什么？

```math
X\rightarrow Y
```

还是只有：

```math
X
```

？

### 3. 它如何表示 \(X\rightarrow Y\)？

线性函数？

树？

距离？

概率？

神经网络？

### 4. 它优化什么目标？

```math
\text{Loss function}
```

是什么？

### 5. 哪些东西是参数？

哪些东西是真正由数据学出来的？

### 6. 哪些东西是超参数？

如何选择？

### 7. 它如何控制过拟合？

是否使用：

- regularization；
- pruning；
- bagging；
- dropout；
- early stopping；
- cross-validation。

### 8. 它在什么情况下容易失败？

这是理解算法非常关键的一步。

# 32. 最终需要真正掌握的不是算法名字，而是几个核心概念

如果把整个机器学习压缩到最重要的知识，实际上是以下几个问题：

```math
\boxed{\text{Representation}}
```

模型如何表示数据关系？

```math
\boxed{\text{Loss}}
```

模型认为什么叫“做错了”？

```math
\boxed{\text{Optimization}}
```

模型如何找到更好的参数？

```math
\boxed{\text{Regularization}}
```

如何避免模型过度复杂？

```math
\boxed{\text{Generalization}}
```

模型能否适用于没见过的数据？

```math
\boxed{\text{Validation}}
```

如何可靠地判断模型到底好不好？

真正理解这些以后，机器学习就不再是一堆彼此独立的算法，而是一套统一的问题求解框架。
