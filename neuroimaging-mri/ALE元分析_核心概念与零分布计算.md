# 激活似然估计（ALE）元分析：核心概念与零分布计算

> 本文经 AI 辅助核查，修正了高斯核的归一化、实验内峰值合并及软件版本差异，并补充零分布与多重比较的区别。文末列出原始方法与官方文档，尚未经人工专家审定。

## 1. ALE 回答什么问题？

激活似然估计（Activation Likelihood Estimation，ALE）是一种**基于坐标的神经影像元分析**：它整合多项 fMRI 或 PET 实验报告的激活峰坐标，检验不同实验是否在某些位置表现出超过随机预期的空间收敛。

这里的“空间收敛”指不同实验报告的位置在空间上聚集。它不是把原始 BOLD 反应幅度或效应量直接加权平均。

| 环节 | 使用或得到什么 |
| --- | --- |
| 输入 | 符合纳入标准的坐标、独立样本信息及样本量等 |
| 空间建模 | 每个峰的定位不确定性图 |
| 实验内合并 | 每项实验的建模激活图（modeled activation map，MA 图） |
| 跨实验合并 | 观察到的 ALE 图 |
| 统计推断 | 零假设下的分布、p 值及多重比较校正 |
| 解释 | 哪些位置存在超过零模型预期的跨实验收敛 |

**论文、实验对比和独立样本不是同一个单位。**一篇论文可能包含多个样本；同一批参与者也可能贡献多个对比。不能把这些对比全部当作独立证据重复计入。[实验及样本依赖性][turkeltaub]

## 2. 为什么把峰坐标表示为空间分布？

### 2.1 高斯形状的直观解释

报告的峰坐标不是完全没有定位误差的点。研究之间的参与者差异、空间标准化等会带来不确定性。

以一维为例，可用下面的函数展示“离中心越远，权重越低”的形状：

```math
h(x)=\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
```

这里 $\mu$ 是中心， $\sigma$ 控制宽度。这个**示意函数**在中心等于 1，但没有归一化；它不能直接作为 ALE 的体素概率公式。

### 2.2 三维概率密度与体素概率

设实验 i 的第 j 个峰为 $c_{ij}$，三维位置为 r。各向同性高斯概率密度可写为：

```math
g_{ij}(r)=
\frac{1}{(2\pi\sigma_i^2)^{3/2}}
\exp\!\left(-\frac{\lVert r-c_{ij}\rVert^2}{2\sigma_i^2}\right)
```

其中， $\lVert r-c_{ij}\rVert$ 是欧氏距离， $\sigma_i$ 是该实验核的宽度参数。密度在整个空间积分为 1，中心密度一般不等于 1。

**概率密度不是某个点的概率。**若 V(v) 表示以 v 为中心的体素区域，则相应的体素概率可表达为：

```math
P_{ij}(v)=\int_{V(v)}g_{ij}(r)\,\mathrm{d}r
\approx g_{ij}(v)\,\Delta V
```

右侧是用体素中心密度乘体素体积的离散近似。实际软件还涉及网格、核截断和分析掩模，具体数值应依实现解释；不能把上面的中心为 1 的示意函数直接代入软件计算。

这些概率用于**定位不确定性模型**，不是“该体素真正激活”的后验概率。[空间不确定性与离散实现][eickhoff2009] [软件的体素体积处理][readme]

### 2.3 核宽度从哪里来？

ALE 的经验不确定性模型考虑参与者之间和模板之间的定位变异。样本量会影响核宽度；在该模型中，较大的样本通常对应较窄的核。

常见宽度记号是**半高全宽（FWHM）**，即高斯曲线达到峰值一半时两侧位置的间距：

```math
\mathrm{FWHM}=2\sqrt{2\ln 2}\,\sigma
```

这不是任意选择一个平滑宽度，也不是直接按样本量对 BOLD 效应量加权。高斯及各向同性都是建模假设，不保证真实定位误差处处严格满足。[核宽度模型][eickhoff2009]

## 3. 同一实验的多个峰：先建立 MA 图

### 3.1 GingerALE 3.0 起采用的最大值法

对同一实验的各峰核，在每个体素取最大值：

```math
\mathrm{MA}_i(v)=\max_{1\le j\le n_i}P_{ij}(v)
```

其中 $n_i$ 是该实验的峰数。这样可避免同一实验中相邻峰的重叠贡献累加，减少峰值报告数量对结果的影响。

这是 Turkeltaub 等提出的非加性处理。官方版本记录说明：GingerALE 3.0 移除了实验内 union／max 的选择，统一使用 max。[原始改进][turkeltaub] [官方版本记录][readme]

### 3.2 旧版并集法应单独标明

早期实验级方法也使用过以下实验内概率并集形式：

```math
\mathrm{MA}^{\mathrm{union}}_i(v)
=1-\prod_{j=1}^{n_i}\left[1-P_{ij}(v)\right]
```

例如，纯算术示例中的两个输入为 0.4、0.5 时，最大值法得到 0.5，而并集法得到 0.7。这里的较大数字仅用于展示运算差别，不代表真实 ALE 核的典型尺度。

**不能把实验内并集法无条件称为现代 GingerALE 的合并方式。**阅读论文时要核对算法、版本和设置，也要区分实验内与实验间的合并。

最大值法本身也不能识别跨论文重复使用的参与者；样本依赖性仍需在整理数据时处理。

## 4. 多项实验的 MA 图：合并成 ALE 图

对 N 项适当组织的实验级证据，在每个体素按并集形式合并：

```math
\mathrm{ALE}(v)=1-\prod_{i=1}^{N}
\left[1-\mathrm{MA}_i(v)\right]
```

所以，这里有两个不同操作：

- **实验内**：非加性方法通常取各峰核的最大值；
- **实验间**：按上述并集形式构造 ALE 统计量。

多项实验在相近位置有较高 MA 值时，该处通常得到较高 ALE 值。但 ALE 值不是“有多少项实验显著”的比例，也不要求所有实验都在该处报告峰。

还需区分三个量：

| 数量 | 含义 |
| --- | --- |
| ALE 值 | 由 MA 图合并得到的空间收敛统计量 |
| 未校正 p 值 | 该数值相对于单位置零分布有多极端 |
| 校正后结果 | 对多个位置或簇同时检验后是否达到指定标准 |

**ALE 值高不等于显著，也不等于神经反应更强。**[随机效应 ALE 与收敛推断][eickhoff2009]

## 5. 零假设是什么？

**零分布**是假设不存在目标效应时，统计量可能取值及其概率的分布。ALE 在这里关注的零假设是：

> 在所规定的搜索空间和空间不确定性模型下，不同实验之间不存在特定的空间对应，观察到的收敛可由随机空间关联解释。

构建 MA 图时已把同一实验的峰及其相互位置组织在一起。零模型主要打破的是**实验之间的位置对应**，不是把所有峰混为一组独立观测。

不能把零假设简单写成“所有峰在不受限制的整个大脑里均匀随机分布”。实际存在分析掩模，例如指定的灰质搜索空间；核宽度、峰数和实验组织也影响零模型。

同样，“保留同一实验的信息”不代表后面每一种校正模拟都保持其峰间几何距离不变。必须区分下面的**单位置数值分布**与**整张随机图的空间统计量**。[零假设及两类计算][eickhoff2012]

## 6. 单位置零分布：从随机抽样到直方图组合

### 6.1 随机抽样的思路

在共同的分析掩模内：

1. 从第一项实验的 MA 图，在掩模内等概率随机取一个体素并读取其值；
2. 从第二项实验独立地按同样规则取值，依次遍历其他实验；
3. 将这些 MA 值按 ALE 公式合并，得到一个零假设下的 ALE 值；
4. 重复抽样，形成经验分布。

每轮得到的是**一个 ALE 数值**，不是一张包含完整空间关系的随机 ALE 图。大量抽样可能仍难准确覆盖很小的右尾概率。[2009 年方法][eickhoff2009]

### 6.2 2012 年的解析思路

如果多个体素具有相同 MA 值，就不必逐个抽取这些体素；可以记录每种数值在掩模内出现的概率。

设掩模为 $\mathcal{V}$，包含 M 个体素。实验 i 的某个 MA 值 a 的概率为：

```math
p_i(a)=
\frac{\#\{v\in\mathcal{V}:\mathrm{MA}_i(v)=a\}}{M}
```

其中 $\#$ 表示计数。实际计算可以用数值分箱近似；**零值所在分箱也必须纳入**，不能只统计峰附近非零体素。

然后把不同实验的数值分布按实验间独立性组合，逐步得到 ALE 的零分布。2012 年方法将其称为非线性直方图积分，也可理解为**经过 ALE 合并函数变换的加权组合**，不是直接对原始 MA 值做普通求和卷积。[解析零分布原始方法][eickhoff2012]

直方图保留了数值出现的频率，丢掉了它们的绝对空间位置。因此，它适合计算单位置的数值分布；仅凭它不能确定哪些体素彼此相邻、形成多大的簇。

### 6.3 为什么两张直方图有 m×n 种组合？

若实验 A 有 m 个可取数值或非空分箱，实验 B 有 n 个，则从 A、B 各取一个值，共有：

```math
m\times n
```

这不同于从同一组 n 个元素中选两个、不计顺序的 $n(n-1)/2$。当 m、n 均为 3 时，共有 9 个组合。

若 A 取 $a_k$ 的概率为 $p_k$，B 取 $b_l$ 的概率为 $q_l$，则：

```math
\Pr(A=a_k,B=b_l)=p_kq_l
```

该组合对应的 ALE 值为：

```math
u_{kl}=1-(1-a_k)(1-b_l)
```

不同组合如果产生相同数值，或落入同一输出分箱，其概率应相加。

### 6.4 一个可手算的完整例子

以下是人为设置的数值分布，用来展示计算，不是实际大脑数据或典型 ALE 数值：

| MA 值 | A 中的概率 | B 中的概率 |
| --- | --- | --- |
| 0 | 0.5 | 0.6 |
| 0.1 | 0.3 | 0.3 |
| 0.2 | 0.2 | 0.1 |

两边各自的概率和都是 1。列出 9 个组合：

| A 值 | B 值 | 合并值 | 组合概率 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0.30 |
| 0 | 0.1 | 0.1 | 0.15 |
| 0 | 0.2 | 0.2 | 0.05 |
| 0.1 | 0 | 0.1 | 0.18 |
| 0.1 | 0.1 | 0.19 | 0.09 |
| 0.1 | 0.2 | 0.28 | 0.03 |
| 0.2 | 0 | 0.2 | 0.12 |
| 0.2 | 0.1 | 0.28 | 0.06 |
| 0.2 | 0.2 | 0.36 | 0.02 |

例如，合并值 0.1 对应两条组合，其总概率为 0.15+0.18=0.33。把所有相同输出合并后，概率总和仍为 1。

若有第三项实验，就把当前输出分布与第三项 MA 值分布继续组合。递归过程不必一次枚举全部实验的笛卡尔积；实际精度还受分箱、浮点运算等影响。

## 7. 从零分布计算未校正 p 值

某体素的观察值为 $\mathrm{ALE}_{\mathrm{obs}}(v)$ 时，右尾概率写为：

```math
p(v)=
\Pr\!\left(
\mathrm{ALE}_{\mathrm{null}}\ge
\mathrm{ALE}_{\mathrm{obs}}(v)
\right)
```

在上面的示例分布中，若观察值为 0.25，达到或超过它的输出只有 0.28、0.36：

```math
p=0.03+0.06+0.02=0.11
```

这只是未校正 p 值。它不是“零假设为真的概率”，也没有处理全脑许多位置同时检验的问题。

## 8. 如何用整图空间模拟进行 FWE 校正？

解析直方图解决的是单位置 ALE 值的分布。GingerALE 的空间随机化校正还需要考虑整张图中出现极端数值或大簇的机会。

| 推断方式 | 每张零模型随机图需要记录什么 |
| --- | --- |
| 体素水平家族错误率（FWE） | 整个搜索空间中的最大 ALE 值 |
| 簇水平 FWE | 在相同成簇阈值下，整张图中的最大簇大小 |

典型流程是：按实际实验的峰数、样本量或核宽度等特征，在指定搜索空间内生成随机坐标，重建完整 ALE 图，并重复计算空间极值分布。不能把单位置直方图当作最大簇分布。

**这里必须注意版本差异：**GingerALE 2.3.6 的版本记录明确修正了簇校正，使用每次模拟的最大簇，而不是把所有簇混在一起。阅读旧论文或旧手册时不能忽略这一点。[官方修订记录][readme] [实现错误与建议][bugfix]

簇水平显著表示整个簇按所用标准达到显著，不能据此断言簇内每个体素都通过了体素水平 FWE。应报告软件版本、搜索掩模、模拟次数、成簇阈值和校正标准。

## 9. 结果的含义与适用边界

ALE 显著收敛不直接证明：

- 该区域的激活幅度最大，或比其他区域更重要；
- 该脑区只参与一种认知功能；
- 该脑区对任务具有直接因果作用；
- 未显著位置完全没有参与任务。

还应检查输入数据是否适合该搜索空间：坐标标准空间与转换、全脑与局部感兴趣区搜索范围、重复样本、对比方向，以及峰值选择和发表报告偏倚。[官方数据准备说明][dataset]

如果分别对记忆、语言、注意等领域开展 ALE，一个脑区在多张图中显著，可以作为跨领域参与的线索，但不能直接当作“神经多效性”的定量指标。认知领域划分、任务差异、研究数量、样本依赖性和阈值都会影响重叠。

“A 领域显著、B 领域不显著”也不等于 A、B 存在显著差异；比较领域差异需要适当的直接检验。上述跨领域讨论是应用层面的解释边界，不是 ALE 算法额外定义的一项统计量。

## 10. 核心流程速记

1. 整理符合纳入标准的峰坐标与独立样本信息。
2. 统一空间，检查重复样本和搜索范围。
3. 按定位不确定性建立每个峰的空间核。
4. 在实验内按指定算法建立 MA 图；GingerALE 3.0 起使用 max。
5. 跨实验按并集形式构造观察 ALE 图。
6. 用 MA 数值分布的独立组合建立单位置零分布，计算未校正 p 值。
7. 用适当的整图空间随机模拟等步骤完成 FWE 推断。
8. 将结果解释为在指定数据与零模型下的空间收敛。
