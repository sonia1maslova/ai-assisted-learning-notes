# 基于重复测量的遗传度分析：原理、计算与结果解读

> 本文经 AI 辅助核对原始研究与统计假设，并补充模型条件及公式显示格式；尚未经人工专家审定。

这份文档介绍如何利用同一个人的多次测量，以及不同人之间的亲缘关系，估计某项指标的遗传度。内容适用于一般的连续型指标，例如脑影像测量、认知测量或生理指标。

本文主要介绍一种**重复测量遗传混合模型**。它将同一个人的多次观测共同纳入分析，尝试区分相对稳定的个体差异与测量之间的波动。模型的核心思想可参考 [Ge 等，2017](https://doi.org/10.1073/pnas.1700765114)。

> **先记住一句话：**遗传度分析研究的是，在特定人群和测量条件下，人与人之间的差异有多少与遗传差异有关。重复测量模型进一步问：如果把每次测量中的短期波动单独考虑，稳定的个体差异中有多少与遗传差异有关？

---

## 1. 遗传度究竟是什么？

假设研究者测量一群人的某项脑指标。不同人的测量值不完全一样：有些人的值较高，有些人的值较低。我们把这些人与人之间的分散程度称为**表型方差**。表型就是研究者测量的特征。

遗传度的基本问题是：

> 这个人群中，表型差异有多大一部分可以归因于遗传差异？

本篇重点讨论**狭义遗传度**（narrow-sense heritability，通常写为 $h^2$）：它关注的是**加性遗传效应**造成的方差，占相应表型方差的比例。

通俗地说，加性遗传效应把多个遗传变异的贡献看作可以相加的部分。这里的方差比例是在指定协变量和模型假设下解释的：调整协变量后，它不一定等于未调整的总体表型方差比例。它不同于涵盖更广泛遗传效应的**广义遗传度**；不同研究的遗传度定义也可能不同，比较前要先看分子和分母。

例如，若某研究估计某指标的遗传度为 0.40，可以这样理解：在该研究人群、测量条件和模型假设下，该指标个体差异的约 40% 可由模型中的加性遗传差异解释。

**这不表示：**

- 某一个人的指标“40%由基因决定、60%由环境决定”；
- 我们已经找到了造成差异的具体基因；
- 该指标不能受到环境或干预的影响；
- 在其他人群、年龄或测量条件下，遗传度一定也是 0.40。

遗传度是**人群中的方差比例**，不是对单个人原因的拆分。其大小会受到人群、环境、测量方式和模型的影响。概念及常见误解可参阅 [Visscher 等，2008](https://doi.org/10.1038/nrg2322)。

## 2. 不测具体基因，也能估计遗传度吗？

可以。一个常见思路是利用**亲缘关系**。

亲属之间通常比无亲缘关系的人更相似，其中一个原因是他们共享更多遗传变异。研究者可以比较：遗传关系越近的两个人，测量结果是否也越相似。

例如，考虑以下几类关系：

| 两个人的关系 | 在常见简化条件下的加性遗传相似程度 | 如何理解 |
|---|---:|---|
| 同一个人 | 1 | 与自己的加性遗传效应完全相同 |
| 同卵双生子 | 约 1 | 两人具有几乎相同的遗传序列 |
| 异卵双生子、全同胞 | 约 0.5 | 平均共享约一半的加性遗传成分 |
| 半同胞 | 约 0.25 | 平均共享程度低于全同胞 |
| 无近亲关系的人 | 约 0 | 在模型的参照条件下近似看作没有近亲关系 |

这些是**模型中常见的预期值**；实际估计可以受家系结构、近交、遗传数据与定义方式影响。

然而，亲属相似也可能是因为他们有相似的生活环境。因此，不能把“家人之间相似”全部当作遗传的证据。模型需要尽可能区分遗传相似和共同环境带来的相似。方差成分的遗传解释依赖模型假设，本身不能证明某种变异对表型的因果作用。

### 2.1 遗传关系矩阵是什么？

**遗传关系矩阵** $K$ 是一张表示每一对研究参与者有多大遗传相似程度的表。它可以由家系谱系推算，也可以通过基因型数据估计；两种方法反映的遗传信息和估计对象不完全相同。谱系模型在其假设下旨在估计加性遗传方差；基于有限 SNP 构造的基因组关系矩阵通常估计由这些标记捕获的遗传方差，不能直接等同于全部加性遗传方差。

一个简化例子如下。A 与 B 是同卵双生子，A 与 C 是全同胞，D 与他们没有近亲关系：

|  | A | B | C | D |
|---|---:|---:|---:|---:|
| A | 1 | 1 | 0.5 | 0 |
| B | 1 | 1 | 0.5 | 0 |
| C | 0.5 | 0.5 | 1 | 0 |
| D | 0 | 0 | 0 | 1 |

常见家系模型中， $K$ 使用的是**加性遗传关系系数**，通常等于亲缘系数的两倍。使用软件时要核对输入要求，避免把“亲缘系数”和“加性遗传关系系数”混用。

### 2.2 共同环境矩阵是什么？

**共同环境矩阵**用来表示：哪些人的环境影响可能相互关联。例如，研究者可能假设同父同母的兄弟姐妹共享某些家庭环境。

需要注意，**同一家族编号不等于遗传关系矩阵**：同一家庭中的同卵双生子、全同胞与半同胞，其遗传相似程度并不一样。家庭编号可以帮助定义共同环境，但应先检查它是否真正对应研究者想表达的共同生活经历。

无论是遗传关系矩阵还是共同环境矩阵，都是为了表达模型中的相似结构。尤其是共同环境，很多时候只能依据家系信息近似，并没有直接测到每个人的实际环境。

## 3. 为什么单次测量可能不够？

同一个人在两次扫描或两次行为测试中的结果通常不会完全一样。这可能来自：

- 扫描仪、数据处理或量表的测量误差；
- 注意力、疲劳、睡眠、情绪等短期状态；
- 测量时间、具体任务条件和其他暂时变化；
- 研究感兴趣的真实生物变化。

如果每个人只有一次测量，观察到的人与人之间的差异，同时包含**相对稳定的差异**和**当次波动**。在标准单次测量模型中，这两者通常无法单独分开。

因此，测量误差较大时，单次测量的总方差中就会包含较多暂时波动。在其他条件不变时，遗传方差占这个较大分母的比例会较小。这可能让我们低估**稳定个体差异的遗传度**。

但这里要先分清研究目标：如果研究者关心的就是一次实际测量结果，那么把单次测量的波动计入分母是合理的。问题不在于单次遗传度“错误”，而在于它回答的问题与稳定成分的遗传度不同。[Ge 等，2017](https://doi.org/10.1073/pnas.1700765114)

## 4. 重复测量提供了什么新信息？

假设每个人都接受了多次测量。我们现在可以观察两种相似性：

1. **同一个人的多次测量是否相似？** 这有助于区分稳定的个体差异与每次测量的波动。
2. **不同人的测量是否随着亲缘关系变近而更相似？** 这有助于估计稳定差异中的遗传成分。

可以用一个简单的示意来理解：

```text
同一个人的多次测量
        ↓
估计稳定的个体差异  +  估计测量之间的波动
        ↓
结合不同人的遗传关系与共同环境关系
        ↓
将稳定个体差异分为 A、C、E 三部分
        ↓
计算稳定成分的遗传度
```

在这个过程中，重复测量提供的是**同一个人内部的变化信息**；亲缘关系提供的是**不同人之间的遗传相似信息**。这两类信息解决不同问题。

四次扫描会形成四条观测记录，但仍然只有一个人。这四条记录不能当作来自四个互相独立的人。

## 5. 模型把差异分成哪几部分？

以下使用一种常见的重复测量 ACE 模型。它把观测结果中的个体差异分为四个方差成分：

| 符号 | 名称 | 通俗含义 |
|---|---|---|
| $V_A$ | 加性遗传方差 | 与加性遗传差异相关、在多次测量中相对稳定的部分 |
| $V_C$ | 共同环境方差 | 模型中亲属共享的、相对稳定的环境影响造成的差异 |
| $V_E$ | 稳定的个体特有方差 | 在一个人多次测量中相对稳定、但未由模型中的 A 或 C 解释的差异 |
| $V_M$ | 测量间波动方差 | 同一个人在不同测量之间出现的波动 |

这里的 $V_M$ 不只是仪器噪声，也可能包含真实的短期生理和心理状态变化。

同样， $V_E$ 是模型中的剩余稳定个体差异，**不能简单认定其中全部都是已经识别的环境因素**。未建模的遗传效应、稳定伪影以及其他来源，也可能影响该成分的解释。

### 5.1 数学表达

第 $i$ 个人第 $j$ 次测量可写作：

```math
y_{ij}=\mathbf{x}_{ij}^{\mathsf T}\boldsymbol{\beta}+a_i+c_i+e_i+\varepsilon_{ij}
```

各部分含义是：

- $y_{ij}$：这一次测得的数值；
- $\mathbf{x}_{ij}^{\mathsf T}\boldsymbol{\beta}$：协变量和群体平均效应，例如年龄、性别或不同扫描的平均差异；
- $a_i$：这个人相对稳定的加性遗传成分；
- $c_i$：与其家人共享的相对稳定环境成分；
- $e_i$：这个人相对稳定的个体特有成分；
- $\varepsilon_{ij}$：这一次测量的暂时波动。

这里的 A、C、E、M 是**统计成分**，不是把每个人身上各类真实原因逐一测出来。模型通过大量人的相似性模式来估计这些成分的方差。

### 5.2 数学表达中的一个重要假设

本篇的简化公式采用以下假设：在研究时间范围内， $a_i$、 $c_i$、 $e_i$ 相对稳定；四类随机成分均值为零、彼此不相关；每次测量的暂时波动相互独立且方差相同。下文的方差和协方差均指已按模型处理固定效应、在给定协变量下的量。

还假设遗传关系矩阵和共同环境矩阵的对角线分别为 $K_{ii}=1$ 和 $H_{ii}=1$，并且计算遗传度时分母大于零。实际基因组关系矩阵的对角线未必恰好为 1，应核对矩阵的定义、尺度和软件处理方式；不能不加说明地套用下面的简化公式。

如果研究的时间跨度很长，或关注发育、疾病进展等真实变化，稳定成分可能随时间改变。此时应考虑扩展模型，而不能自动把全部时间变化视为噪声。

## 6. 模型如何判断这四部分？

模型依靠的是**不同观测之间的相似性结构**。它并不是先给每个人贴上“遗传部分是多少”的标签，再将这些标签相加。

### 6.1 同一个人的不同测量

同一个人的不同测量共享其 $a_i$、 $c_i$ 和 $e_i$。如果每次波动独立，则不同测量之间的相似性由 A、C、E 的稳定部分贡献。

在简单模型假设下：

```math
\mathrm{Cov}(y_{i1},y_{i2})=V_A+V_C+V_E
```

这里假设协变量的影响已由模型处理，并使用上节的对角线和独立性假设；Cov 表示两个测量值如何一起变化。若对角线并非均为 1，同一人的稳定协方差应写为 $K_{ii}V_A+H_{ii}V_C+V_E$。单次测量的波动增加每次结果的方差，但在独立假设下不增加两次测量之间的协方差。

### 6.2 两个不同的人

不同人的相似性则取决于他们的遗传关系以及共同环境关系：

```math
\mathrm{Cov}(y_i,y_k)=K_{ik}V_A+H_{ik}V_C
```

其中， $K_{ik}$ 是两人的加性遗传关系， $H_{ik}$ 表示模型中两人的共同环境关系。简单模型中，不同人的个体特有部分和测量波动互不相关。

比如，若一对同卵双生子和一对全同胞被假设具有相同程度的共同环境，而同卵双生子的测量结果更相似，那么模型可利用两类亲缘关系的差异来估计 A。要真正区分 A 和 C，需要足够且多样的亲属关系；只知道谁属于同一个家庭，通常不够。

### 6.3 矩阵形式：可选阅读

把所有人的所有测量拼接起来，观测值的协方差可以写成：

```math
\mathrm{Cov}(\mathbf y)
=V_A TKT^{\mathsf T}
+V_C THT^{\mathsf T}
+V_E TT^{\mathsf T}
+V_M I
```

不必记住矩阵乘法的细节，重点是每一项表达一种不同的相似模式：

- $T$：记录每一次测量属于哪一个人；
- $K$：人与人之间的遗传关系；
- $H$：人与人之间假设的共同环境关系；
- $TT^{\mathsf T}$：哪些测量属于同一个人；
- $I$：基础模型中每次独立的波动。

这与 [Ge 等，2017](https://doi.org/10.1073/pnas.1700765114) 的重复测量遗传混合模型是同一种基本建模逻辑。 $H$ 在原文中使用其他符号表示。

## 7. 三种常见遗传度：分母不同，问题也不同

如果满足上述基础模型的假设，且各分母大于零，可定义以下三个模型方差比例。下面的下标 single、stable 和 mean 分别表示单次测量、稳定成分和多次平均；它们均为协变量调整后的模型尺度上的量。

### 7.1 单次观测的遗传度

```math
h^2_{\mathrm{single}}=\frac{V_A}{V_A+V_C+V_E+V_M}
```

**问题：**单次实际测量结果的总体差异中，多少与加性遗传差异有关？

分母包括稳定个体差异和一次测量中的波动。

### 7.2 稳定成分的遗传度

```math
h^2_{\mathrm{stable}}=\frac{V_A}{V_A+V_C+V_E}
```

**问题：**在相对稳定的个体差异中，多少与加性遗传差异有关？

这个量也被称为**非瞬时遗传度**（non-transient heritability）。分母不包括基础模型中每次独立的波动部分。

### 7.3 多次平均值的遗传度

如果每个人都有相同的 $m$ 次测量（ $m$ 为正整数），且每次波动**独立、同方差**，那么多次平均后，波动方差为 $V_M/m$：

```math
h^2_{\mathrm{mean}}=\frac{V_A}{V_A+V_C+V_E+V_M/m}
```

**问题：**如果实际使用每个人的多次测量平均值，平均值的个体差异中多少与加性遗传差异有关？

如果不同测量之间的波动相关，平均值的波动方差要把协方差一起计算，通常不能直接写成 $V_M/m$。如果不同人有不同的测量次数，平均后的残差方差也会随人而异，需要在建模时处理。

**三种结果的分子相同，但分母不同。** 因此，不能仅因为稳定遗传度更高，就说联合模型发现了更强的遗传作用。它首先反映的是研究者换了一个分母和研究对象。[Risk 与 Zhu，2018](https://doi.org/10.1073/pnas.1719250115)

## 8. 用具体数字走一遍

下面的数字完全是**假设例子**，仅用于说明计算，不对应任何真实研究结果。

假设模型估计：

| 方差来源 | 假设值 |
|---|---:|
| 加性遗传 $V_A$ | 0.30 |
| 共同环境 $V_C$ | 0.15 |
| 稳定个体特有部分 $V_E$ | 0.25 |
| 每次测量间波动 $V_M$ | 0.30 |
| 单次测量总方差 | 1.00 |

**第一步：计算单次观测遗传度。**

```math
h^2_{\mathrm{single}}=\frac{0.30}{0.30+0.15+0.25+0.30}=0.30
```

解释：单次测量的个体差异中，模型估计 30% 与加性遗传差异有关。

**第二步：计算稳定成分遗传度。**

```math
h^2_{\mathrm{stable}}=\frac{0.30}{0.30+0.15+0.25}\approx0.429
```

解释：只看相对稳定的个体差异时，模型估计约 42.9% 与加性遗传差异有关。

**第三步：假设将四次独立、同方差的测量取平均。**

```math
h^2_{\mathrm{mean},\,m=4}=\frac{0.30}{0.30+0.15+0.25+0.30/4}
=\frac{0.30}{0.775}\approx0.387
```

解释：四次平均会减少每次独立波动的影响，平均值遗传度约为 38.7%，介于上面两个量之间。

这些计算并不意味着 A 从 0.30 变大了。三次计算使用的是同一个假设的遗传方差，改变的是分母。

## 9. 遗传度与重测可靠性有什么区别？

**重测可靠性**关心的是：同一个人重复测量时，结果能否相对稳定地反映人与人之间的差异。

**遗传度**关心的是：个体差异中有多少与遗传差异有关。

它们的分子不同。在上述简单模型条件下，固定效应处理后，单次测量的稳定方差比例记为 $R_{\mathrm{stable}}$，可以写成：

```math
R_{\mathrm{stable}}=\frac{V_A+V_C+V_E}{V_A+V_C+V_E+V_M}
```

在特定的随机截距、独立同方差误差和一致性定义下，这个比例可对应一种单次测量的**组内相关系数**（intraclass correlation coefficient，ICC）。ICC 有多种定义；是否计算一致性、是否要求绝对一致、单次测量还是多次平均，都会影响解释，不能把它们一概当作同一个值。[Koo 与 Li，2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4913118/)

沿用上一节的假设数值，稳定方差比例为：

```math
\frac{0.30+0.15+0.25}{1.00}=0.70
```

这表示：在这个简单模型的条件下，单次测量的总差异中约 70% 是相对稳定的个体差异。它包含 A、C 和 E；其中遗传度的分子只包含 A。

因此，一个指标可以很稳定，却主要反映稳定的非遗传差异；也可能稳定部分中的遗传比例较高，但实际单次测量包含较大波动。**遗传度不能代替可靠性，也不能代替效度。**

此外，比较两次**全脑空间图的 Pearson 相关**，主要反映两张图的空间分布是否相似；它不是某一个脑区的跨人群 ICC。不同指标应分别解释。

## 10. 为什么不直接把多次测量平均？

直接平均是一种有用且容易理解的方法。如果各次波动相互独立且同方差，平均值会减少波动，因此通常比一次测量更稳定。

但平均之后，模型通常只能看到每个人的一个平均值。在每人测量次数相同、且波动独立同方差的条件下，**稳定个体特有方差 $V_E$** 和**平均后仍剩下的测量间波动 $V_M/m$** 会混在一起，无法仅凭这个平均值再分别估计。于是，基于平均值估计的遗传度通常对应的是“平均值的遗传度”，不是本篇定义的“稳定成分遗传度”。

两种做法各有用途：

| 做法 | 主要回答的问题 | 主要限制 |
|---|---|---|
| 每次扫描分别估计 | 不同扫描各自的遗传度如何 | 不直接将稳定差异和测量间波动分开；估计可能在扫描间变化 |
| 先对每人多次测量取平均 | 平均指标的遗传度如何 | 通常不能再单独估计稳定个体特有方差和剩余测量波动 |
| 多次测量联合建模 | 稳定差异和测量间波动分别有多大，稳定部分的遗传度如何 | 模型更复杂，更依赖假设，结果可能不稳定 |

重复测量联合建模并不保证显著性更强。增加方差成分后，参数估计的不确定性也可能增加。样本较小、重复次数少或波动很大时，模型可能更难稳定估计。[Ge 等，2017](https://doi.org/10.1073/pnas.1700765114)

## 11. 实际分析通常怎么做？

### 第一步：明确研究问题和测量指标

先说明希望估计的是：单次观测的遗传度、多次平均值的遗传度，还是稳定成分的遗传度。明确指标如何计算、数值方向、单位及不同测量是否可比。

如果要逐脑区分析，每个脑区对应一个指标，可分别估计；若要研究多个脑区之间的遗传共享，则需要额外的多变量模型，不能直接从单脑区遗传度图得出。

### 第二步：整理测量与协变量

每条记录需要能识别“哪个人、哪一次测量”，并对应上测量值。年龄、性别、测量时间、扫描条件等协变量应根据研究目的和实际数据预先确定。

不同扫描条件的平均水平如果不同，可以将条件作为固定效应考虑。它处理的是**条件之间的平均差异**，不会自动处理同一个人在某一天或某种条件下额外相关的波动。

### 第三步：建立遗传与共同环境关系

根据家系或基因型数据建立适用的 $K$，并确保顺序与测量记录中的人员顺序一致。根据研究设计定义共同环境矩阵 $H$，说明它来自实测信息还是近似假设。

研究者要检查：亲缘关系是否足以区分 A 和 C，编码是否正确，矩阵是否满足模型所需的数学条件。关系信息不足时，模型即使给出一个数值，也不一定能可靠地区分多个成分。

### 第四步：拟合重复测量混合模型

常用方法是**限制最大似然**（restricted maximum likelihood，REML）。可以把它理解为：在考虑固定效应后，寻找一组方差成分，让模型预测的观测相似性尽可能符合实际数据。

REML 是一种参数估计方法，不是单独的可靠性检验，也不自动保证模型假设正确。

### 第五步：检查模型结果

需要检查方差是否有效、优化过程是否收敛，以及不同初始值是否得到相近结果。某些方差可能被估计为零；这称为**边界结果**。边界结果本身可能合理，但需要特别检查模型稳定性和推断方法。

还应关注置信区间、样本量、家系结构、异常值和数据缺失。不同脑区若有不同有效样本，也应分别记录。

### 第六步：报告估计和不确定性

至少说明：

1. 遗传度的具体定义和分母；
2. 每人测量次数、实际人数与亲属结构；
3. 协变量、遗传关系和共同环境的定义；
4. 方差成分、遗传度估计及其置信区间或标准误；
5. 使用的显著性检验，以及跨多个指标时的多重比较校正范围；
6. 收敛情况和敏感性分析。

统计显著性并不等于估计精确；较宽的置信区间仍表示结果不确定。

## 12. 重复测量的误差为什么需要仔细考虑？

### 12.1 同一天测量可能更相似

假设每个人在两天各测两次。同一天的两次测量可能共享当天的疲劳、状态或环境；因此，它们的暂时波动可能比跨天的两次更相似。

基础模型假定每次波动独立。如果这种假设不成立，模型可能无法正确区分稳定个体差异与共同的当天波动。

可考虑的办法包括：

- 增加“个人 × 测量日”的随机效应，单独表示同一个人在同一天的共同波动；
- 根据研究设计设定更合适的误差相关结构；
- 将同一天的测量进行合理汇总，再以不同天的数据作为重复测量，作为敏感性分析。

这些办法有不同假设，也会改变可估计的信息或目标。增加随机效应还需要足够的数据；不能机械地把所有复杂项同时加入模型。

### 12.2 系统性差异和波动相关不是一回事

假设第二天所有人平均都比第一天高一些。加入“测量日”固定效应可以处理这种**群体平均差异**。

但如果同一天的两次测量对每个人来说仍有额外相似性，固定效应不会自动消除这种**个体内误差相关**。两者需要分别检查。

### 12.3 真实变化与噪声需要按研究问题区分

疲劳或情绪波动可能是可靠性研究中需要考虑的短期变化；在另一项关注情绪变化的研究里，它们可能正是有意义的信号。

所以，模型中的 $V_M$ 更适合称为“测量间波动”或“暂时成分”，而不是一概称为“无用噪声”。

## 13. 如何判断遗传度是否显著？

遗传度点估计回答的是“估计值是多少”；统计检验还要问“数据是否足以排除模型中遗传方差为零的情况”。两者不同。

一种方法是比较两个嵌套模型：

- 完整模型：允许 $V_A$ 大于或等于零；
- 对照模型：将 $V_A$ 固定为零。

通过比较两个模型与数据的拟合情况，可以构造**似然比检验**。但因为方差不能小于零， $V_A=0$ 位于参数空间边界，普通的标准检验分布并不一定适用；其他方差成分也在边界时，情况可能更复杂。需要依据具体模型选择合适的边界校正、参数化模拟等方法，并检查其适用条件；不能对所有情况统一套用同一种混合卡方分布。若比较限制似然，模型应使用相同的观测数据和固定效应设计矩阵。[Self 与 Liang，1987](https://doi.org/10.1080/01621459.1987.10478472)

如果对许多脑区分别检验，应说明多重比较如何控制，例如对预先确定的一组脑区使用 FDR 校正。是否显著，还取决于样本量、亲属类型、噪声和模型假设，并不只取决于遗传度点估计。

## 14. 方法适用的条件与局限

### 14.1 遗传相似与环境相似可能难以分开

亲属通常既共享遗传，也共享环境。如果遗传相似程度和共同环境的划分高度重合，A 与 C 可能很难分别估计。加入不同类型的亲属、改进环境测量、比较不同假设，可以帮助评估这一问题。

经典双生子分析常涉及“不同类型双生子的共同环境相似程度可比较”等假设；如果假设不合适，遗传度解释可能受到影响。

### 14.2 稳定伪影不会自动消失

重复测量帮助分离的是“会随测量变化的部分”和“在这些测量中相对稳定的部分”。如果某种伪影在同一个人身上多次存在，例如稳定的头动倾向或配准偏差，它可能也被模型当成稳定差异。

因此，稳定成分并不自动等于纯粹的生物信号。仍需仔细预处理、质量控制和必要的敏感性分析。[Ge 等，2017](https://doi.org/10.1073/pnas.1700765114)

### 14.3 不是所有研究都满足“遗传影响稳定”的假设

基础模型假设每次测量共享同一个稳定遗传成分。如果不同时间或条件对应不同的遗传影响，可能需要允许遗传效应随时间或条件变化的多变量或纵向模型。

### 14.4 重复次数和人数解决的问题不完全相同

增加重复测量有助于认识个体内波动；增加人数及不同亲属类型有助于估计人与人之间的遗传和环境相似。大量重复扫描不能完全替代足够的独立家庭和适当的亲缘结构。

### 14.5 缺失数据需要单独检查

一般重复测量模型可以允许不同人的测量次数不同，但具体程序未必支持。即使软件能够处理不完整记录，研究者仍应检查缺失是否与年龄、健康状态、测量值或其他因素有关，以及缺失处理的假设是否合理。例如，基于似然忽略缺失机制通常需要缺失随机等条件；软件能拟合不完整记录并不自动保证估计无偏。

### 14.6 遗传度不是预测准确率，也不是具体基因定位

遗传度估计一个人群中差异的方差比例。它不直接告诉我们能否根据一个人的基因预测其脑指标，也不能告诉我们哪些特定基因负责。基于家系、全基因组常见变异或其他数据得到的遗传度，捕捉的遗传范围可能不同，不宜不加区分地比较。

## 15. 真实研究中如何应用？

[Ge 等（2017）](https://doi.org/10.1073/pnas.1700765114) 提出了利用重复测量区分稳定个体差异与测量间波动的遗传混合模型，并将其用于静息态功能连接研究。该研究的重点是估计稳定成分的遗传度，同时保留对模型假设和统计功效的讨论。

[Gu 等（2021）](https://doi.org/10.1038/s41467-021-25184-4) 将这一思路应用于脑区结构—功能连接耦合，并将每人的四次静息态扫描分别纳入遗传分析。这个例子说明：重复测量方法并不限于某一种脑指标，关键在于测量、亲缘关系和协方差结构是否符合模型要求。

## 16. 常见问题

**Q1：遗传度高，是否说明这个指标更可靠？**  
不一定。遗传度和可靠性分子不同。应单独评估重测可靠性、遗传度和其他效度证据。

**Q2：同一个人的四次测量，能当作四个人吗？**  
不能。四次测量共享同一个人的稳定特征，联合模型要明确表示这种依赖关系。

**Q3：加入家族随机截距，就是遗传度分析吗？**  
不一定。家族随机截距通常描述同一家族成员的共同相似性；遗传度模型还需要区分同卵双生子、全同胞等不同的遗传相似程度，通常需要遗传关系矩阵或相应的家系结构。

**Q4：稳定成分遗传度比单次遗传度高，说明模型一定更好吗？**  
不一定。两个量的分母不同，估计值更高是可以预期的；模型是否合适还需检查假设、稳定性和不确定性。

**Q5：模型能告诉我是哪一种基因导致了这个脑指标吗？**  
不能。方差成分模型估计整体遗传差异与表型差异的关系；定位特定遗传变异需要其他分析。

**Q6：遗传度不显著，能说明不存在遗传影响吗？**  
不能。它也可能反映样本量有限、估计不精确、测量波动较大或模型难以区分方差成分。应结合置信区间和研究设计解释。
