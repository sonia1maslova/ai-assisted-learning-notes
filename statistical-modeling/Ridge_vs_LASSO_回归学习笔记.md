# Ridge 回归与 LASSO 回归：原理、差异与适用场景

## 1. 为什么需要正则化回归？

在线性回归中，我们通常希望用一组特征 $X_1, X_2, \dots, X_p$ 去预测一个结果 $Y$：

```math
Y=\beta_0+\beta_1X_1+\beta_2X_2+\cdots+\beta_pX_p+\epsilon
```

普通最小二乘回归（OLS）的目标，是找到一组回归系数，使残差平方和最小：

```math
\mathrm{RSS}
=
\sum_{i=1}^{n}(y_i-\hat y_i)^2
```

OLS 在很多情况下很好用，但当出现以下问题时会变得不稳定：

- 特征数量很多；
- 不同特征之间高度相关，也就是多重共线性；
- 样本量相对于特征数量较少；
- 模型容易过拟合；
- 回归系数对样本的轻微变化非常敏感。

这时可以使用**正则化回归（regularized regression）**。

核心思想是：

> 不仅要求模型拟合数据，还对“过大的回归系数”进行惩罚。

Ridge 和 LASSO 都属于正则化线性回归，但它们使用不同的惩罚方式。

---

# 2. Ridge 回归

## 2.1 基本思想

Ridge 回归又称：

- 岭回归；
- L2 正则化回归。

它的目标函数为：

```math
\mathrm{RSS}
+
\lambda\sum_{j=1}^{p}\beta_j^2
```

也就是：

```math
\sum_{i=1}^{n}(y_i-\hat y_i)^2
+
\lambda
\left(
\beta_1^2+\beta_2^2+\cdots+\beta_p^2
\right)
```

其中：

- 第一部分是模型拟合误差；
- 第二部分是对回归系数大小的惩罚；
- $\lambda$ 控制惩罚强度。

当：

```math
\lambda=0
```

时，Ridge 就退化为普通 OLS。

随着 $\lambda$ 增大，回归系数会越来越向 0 收缩。

---

## 2.2 Ridge 为什么适合高度相关的特征？

假设有两个高度相关的变量：

```math
r(X_1,X_2)=0.95
```

由于它们携带的信息非常相似，OLS 很难判断：

> 到底应该把预测作用分给 $X_1$，还是分给 $X_2$？

因此可能出现非常不稳定的系数组合，例如：

```math
\beta_1=3,\quad\beta_2=-1
```

换一批样本以后又可能变成：

```math
\beta_1=1.2,\quad\beta_2=0.8
```

虽然总体预测可能差不多，但单个系数变化很大。

Ridge 会惩罚大的系数，因此更倾向于让高度相关的变量**共同分担预测权重**。

例如：

```math
\beta_1\approx0.9,\quad\beta_2\approx0.8
```

因此 Ridge 的一个重要特点是：

> 对于一组彼此高度相关的特征，Ridge 往往倾向于把它们一起保留下来，并让系数较稳定地分布在这些变量之间。

---

## 2.3 从矩阵角度理解 Ridge

OLS 的解是：

```math
\hat{\boldsymbol{\beta}}
=
(X^\top X)^{-1}X^\top y
```

如果特征之间高度相关， $X^\top X$ 会接近奇异矩阵，求逆非常不稳定。

Ridge 的解则是：

```math
\hat{\boldsymbol{\beta}}_{\mathrm{Ridge}}
=
(X^\top X+\lambda I)^{-1}X^\top y
```

它相当于在 $X^\top X$ 的对角线上加入一个正数。

这样可以使矩阵更加稳定，从而降低回归系数的方差。

所以从统计学角度看：

```math
\text{Ridge}
=
\text{增加一点 Bias}
+
\text{显著降低 Variance}
```

这是典型的 bias–variance tradeoff。

---

# 3. LASSO 回归

## 3.1 基本思想

LASSO 全称：

**Least Absolute Shrinkage and Selection Operator**

中文常译为：

**最小绝对收缩与选择算子**。

LASSO 使用的是 L1 惩罚：

```math
\mathrm{RSS}
+
\lambda\sum_{j=1}^{p}|\beta_j|
```

即：

```math
\sum_{i=1}^{n}(y_i-\hat y_i)^2
+
\lambda
\left(
|\beta_1|
+
|\beta_2|
+
\cdots
+
|\beta_p|
\right)
```

与 Ridge 的区别在于：

Ridge 使用：

```math
\beta_j^2
```

而 LASSO 使用：

```math
|\beta_j|
```

这个看起来只是一个小变化，但会产生非常重要的结果。

---

# 4. Ridge 与 LASSO 最核心的区别

Ridge 会把系数压向 0，但通常不会真正变成 0。

LASSO 则可以直接让某些系数变成：

```math
\beta_j=0
```

因此：

> LASSO 不仅能够正则化，还能够自动完成变量选择。

例如原来有：

```math
X_1,X_2,X_3,X_4,X_5
```

LASSO 最后可能得到：

```math
\beta_1=0.8
```

```math
\beta_2=0
```

```math
\beta_3=0
```

```math
\beta_4=-0.5
```

```math
\beta_5=0
```

那么最终模型实际上只保留：

```math
X_1,\;X_4
```

因此 LASSO 会得到一个**稀疏模型（sparse model）**。

---

# 5. 为什么 LASSO 会产生 0，而 Ridge 通常不会？

这个差异可以从约束条件理解。

Ridge 可以写成：

```math
\sum_j\beta_j^2\leq t
```

其约束区域在二维空间中是一个圆。

LASSO 则是：

```math
\sum_j|\beta_j|\leq t
```

在二维空间中，它对应一个菱形。

LASSO 的菱形存在尖角，而且尖角恰好位于坐标轴上。

当损失函数的等高线逐渐接触约束区域时，很容易碰到这些尖角。

一旦落在坐标轴上，就意味着：

```math
\beta_j=0
```

因此 LASSO 能够自然地产生稀疏解。

而 Ridge 的圆形边界很光滑，通常不会恰好落在：

```math
\beta_j=0
```

的位置。

---

# 6. 当特征彼此高度相关时，两者行为有什么不同？

这是 Ridge 和 LASSO 非常重要的区别。

假设：

```math
X_1,X_2,X_3
```

高度相关，并且都能预测 $Y$。

## Ridge 的倾向

Ridge 往往会：

> 三个变量都保留。

然后把预测权重分散在三者之间：

```math
\beta_1=0.4,\quad
\beta_2=0.35,\quad
\beta_3=0.38
```

这种行为通常称为一种 **grouping effect**。

因此，如果一组变量本身代表同一个潜在信息来源，Ridge 往往比较合适。

---

## LASSO 的倾向

LASSO 则可能：

> 从这一组高度相关变量中选择其中一个或少数几个。

例如：

```math
\beta_1=1.0
```

```math
\beta_2=0
```

```math
\beta_3=0
```

但这里需要注意：

如果 $X_1,X_2,X_3$ 非常相似，那么 LASSO 选择哪一个，有时会比较不稳定。

换一批数据后可能变成：

```math
\beta_1=0
```

```math
\beta_2=0.95
```

```math
\beta_3=0
```

这并不一定表示：

> $X_2$ 在生物学或理论上比 $X_1$ 更重要。

它可能只是由于三者高度相关，模型只需要其中一个就能完成预测。

---

# 7. Ridge 与 LASSO 的对比

| 特点 | Ridge | LASSO |
|---|---|---|
| 正则化类型 | L2 | L1 |
| 惩罚项 | $\sum_j\beta_j^2$ | $\sum_j\lvert\beta_j\rvert$ |
| 系数收缩 | 是 | 是 |
| 系数是否能变成严格的 0 | 通常不会 | 可以 |
| 是否自动变量选择 | 否 | 是 |
| 最终模型是否稀疏 | 通常不是 | 通常是 |
| 高度相关变量 | 倾向于共同保留 | 可能只选其中部分 |
| 系数稳定性 | 通常较高 | 在强共线性下可能不稳定 |
| 解释性 | 保留很多变量 | 更容易得到简洁模型 |
| 预测任务 | 常常非常稳定 | 常常表现良好 |
| 高维数据 | 适合 | 适合 |

---

# 8. 一个直观例子

假设你有 100 个脑影像特征预测行为表现。

其中：

- 10 个视觉网络特征高度相关；
- 10 个默认网络特征高度相关；
- 10 个注意网络特征高度相关；
- 其他特征也存在不同程度相关性。

如果使用 Ridge：

模型可能会让同一网络中的多个相关特征都保留下来。

例如：

```math
X_1=0.18
```

```math
X_2=0.16
```

```math
X_3=0.14
```

```math
X_4=0.12
```

此时可以理解为：

> 这一组相关特征整体对预测有贡献。

如果使用 LASSO：

模型可能只留下：

```math
X_2=0.35
```

而：

```math
X_1=X_3=X_4=0
```

此时更像是在问：

> 如果我只想保留一个较小的特征集合，哪些变量足以完成预测？

因此二者解决的问题略有不同。

---

# 9. Ridge 更适合什么情况？

Ridge 往往适合以下场景：

### 9.1 特征之间存在强相关

例如：

- 脑区之间的功能连接；
- 相邻脑区指标；
- 基因表达；
- 多个相近频段的神经信号；
- 多个行为量表维度。

如果这些变量本身就高度相关，而且不希望强行只保留其中一个，那么 Ridge 很合适。

---

### 9.2 更重视预测稳定性

如果主要目标是：

> 尽可能稳定地预测新的样本

而不是得到一个非常稀疏、非常简洁的变量集合，那么 Ridge 通常是很好的选择。

---

### 9.3 认为很多特征都有一点作用

如果你认为真实机制可能是：

> 很多变量都有小的贡献。

那么 Ridge 的假设更加合理。

---

# 10. LASSO 更适合什么情况？

LASSO 往往适合：

### 10.1 希望自动进行特征选择

比如：

1000 个特征中，希望筛选出几十个最有预测价值的特征。

---

### 10.2 希望模型更容易解释

例如最终模型只剩：

```math
X_3,\;X_{15},\;X_{37}
```

这比保留全部 100 个变量更容易解释。

---

### 10.3 认为真正有效的变量数量比较少

LASSO 隐含了一种思想：

> 真实信号可能是稀疏的。

也就是说：

很多变量其实没作用，只有少数变量真正重要。

---

# 11. $\lambda$ 到底是什么？

无论 Ridge 还是 LASSO，都有一个核心参数：

```math
\lambda
```

它控制：

> 正则化到底有多强。

当：

```math
\lambda=0
```

模型就是普通 OLS。

当 $\lambda$ 较小时：

- 系数轻微收缩；
- 模型更加接近 OLS。

当 $\lambda$ 较大时：

- 系数明显缩小；
- 模型复杂度下降。

对于 LASSO，随着 $\lambda$ 增大，会有越来越多系数直接变成 0。

---

# 12. $\lambda$ 应该怎么选择？

通常不会人为指定一个固定值。

最常见的方法是：

**交叉验证（cross-validation）**。

例如：

```math
5\text{-fold CV}
```

或：

```math
10\text{-fold CV}
```

基本思路是：

尝试很多不同的：

```math
\lambda_1,\lambda_2,\lambda_3,\dots
```

然后选择在验证数据上预测性能最好的 $\lambda$。

所以：

> $\lambda$ 是一个需要通过数据调优的超参数。

---

# 13. 为什么正则化前通常要标准化特征？

这一点非常重要。

假设：

```math
X_1
```

的范围是：

```math
0\sim1
```

而：

```math
X_2
```

的范围是：

```math
0\sim10000
```

因为 Ridge 和 LASSO 直接惩罚：

```math
\beta_j
```

如果不同特征尺度差异很大，系数大小本身就不能公平比较。

因此通常先进行标准化：

```math
X_j^{*}
=
\frac{X_j-\bar X_j}{SD(X_j)}
```

使每个特征：

```math
Mean=0,\quad SD=1
```

然后再进行 Ridge 或 LASSO。

所以一个重要原则是：

> Ridge / LASSO 通常应在标准化特征后使用。

---

# 14. Ridge 与 LASSO 并不是传统意义上的显著性检验

这一点尤其重要。

普通线性模型中我们经常关注：

```math
\beta,\quad t,\quad p
```

但 Ridge 和 LASSO 的主要目标通常是：

> 提升预测性能和模型稳定性。

它们并不是为了传统的：

```math
H_0:\beta_j=0
```

显著性检验而设计的。

因此：

**LASSO 把一个系数压成 0，并不等价于传统统计意义上的“这个变量不显著”。**

同样：

**LASSO 保留一个变量，也不等价于“该变量具有统计学显著性”。**

这是预测建模和传统推断统计之间一个非常重要的区别。

---

# 15. Ridge 与 LASSO 的核心思想差异

可以把两者想象成两种不同的问题。

Ridge 更像是在问：

> “这些变量中很多可能都有作用，我如何稳定地估计它们的整体贡献？”

LASSO 更像是在问：

> “如果我只保留一小部分变量，哪些变量足以完成预测？”

因此：

```math
\boxed{
\text{Ridge：保留 + 收缩}
}
```

而：

```math
\boxed{
\text{LASSO：选择 + 收缩}
}
```

---

# 16. 一个非常简化的比喻

假设有 10 个人共同完成一个项目，而且他们的工作内容高度重叠。

### OLS

试图非常精确地判断：

> 每个人到底贡献了百分之多少？

由于大家工作高度重合，这个判断可能非常不稳定。

### Ridge

会说：

> 既然大家的贡献难以完全区分，就让大家都保留，但不要给任何一个人过大的权重。

### LASSO

会说：

> 为了得到一个简洁模型，我只保留几个最能代表这组信息的人。

所以：

- Ridge 更重视稳定；
- LASSO 更重视稀疏和选择。

---

# 17. 如果 Ridge 和 LASSO 都有优点怎么办？

这就引出了：

# Elastic Net

Elastic Net 同时加入 L1 和 L2 惩罚：

```math
\mathrm{RSS}
+
\lambda
\left[
\alpha\sum_j|\beta_j|
+
(1-\alpha)\sum_j\beta_j^2
\right]
```

其中：

- $\alpha=1$：接近 LASSO；
- $\alpha=0$：接近 Ridge；
- $0<\alpha<1$：介于两者之间。

Elastic Net 特别适合：

> 特征很多，而且不同特征之间存在明显的相关结构，同时又希望做一定程度的变量选择。

因此在：

- 神经影像；
- 基因组学；
- 高维生物医学数据；

中非常常见。

---

# 18. 三种方法的整体关系

可以把它们理解成：

```text
普通线性回归 OLS
        │
        ├── Ridge
        │      L2 penalty
        │      ↓
        │   系数整体收缩
        │   保留相关变量
        │   提高稳定性
        │
        ├── LASSO
        │      L1 penalty
        │      ↓
        │   系数整体收缩
        │   部分系数变成 0
        │   自动变量选择
        │
        └── Elastic Net
               L1 + L2
               ↓
            同时兼顾
            稳定性 + 稀疏性
```

---

# 19. 最值得记住的区别

如果只记住最核心的几句话，可以记下面这些：

### Ridge

```math
\boxed{
\mathrm{RSS}+\lambda\sum\beta_j^2
}
```

特点：

- L2 正则化；
- 收缩系数；
- 一般不会把系数压到严格的 0；
- 高度相关变量倾向于共同保留；
- 可以显著改善多重共线性导致的不稳定；
- 特别适合强调预测稳定性的场景。

---

### LASSO

```math
\boxed{
\mathrm{RSS}+\lambda\sum|\beta_j|
}
```

特点：

- L1 正则化；
- 收缩系数；
- 可以把部分系数压到严格的 0；
- 可以自动进行变量选择；
- 得到稀疏模型；
- 高度相关变量之间可能只留下一个或少数几个；
- 更适合希望得到简洁特征集合的场景。

---

# 20. 一句话总结

最简洁地说：

> **Ridge 的核心目标是稳定系数，LASSO 的核心优势是产生稀疏模型。**

进一步说：

> 当很多相关变量可能都包含有用信息时，Ridge 通常更自然；当你认为只有少数变量真正重要，并且希望自动进行变量选择时，LASSO 通常更合适。

而如果：

> 特征很多、相关性很强，同时又希望进行一定程度的变量选择，

那么可以进一步考虑：

```math
\boxed{\text{Elastic Net}}
```

它可以看作 Ridge 与 LASSO 的折中方案。
