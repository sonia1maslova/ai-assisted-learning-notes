# 统计建模中的矩阵基础知识

## 1. 矩阵在统计模型中的作用

现代统计模型常写成：

```math
Y=X\beta+\epsilon
```

其中：

-   Y：观测结果
-   X：设计矩阵
-   β：参数
-   ε：误差

矩阵用于组织大量样本和变量之间的关系。

------------------------------------------------------------------------

## 2. 矩阵乘法

矩阵乘法的核心规则：

一个矩阵的行，与另一个矩阵的列进行内积。

即：

行 × 列 = 结果中的一个元素。

例如：

```math
A=\begin{bmatrix}1&2\\3&4\end{bmatrix}
```

```math
B=\begin{bmatrix}5&6\\7&8\end{bmatrix}
```

AB：

第一项：

```math
1\times5+2\times7=19
```

所以矩阵乘法本质是：

> 将多个变量按照权重进行组合。

------------------------------------------------------------------------

## 3. 统计模型中的矩阵乘法

线性模型：

```math
Y=X\beta
```

表示：

预测结果 = 输入变量 × 参数权重

例如：

```math
Y=\beta_0+\beta_1X_1+\beta_2X_2
```

矩阵形式就是：

```math
Y=X\beta
```

------------------------------------------------------------------------

## 4. 矩阵转置 Xᵀ

矩阵转置：

交换矩阵的行和列。

例如：

```math
X=\begin{bmatrix}1&2\\3&4\end{bmatrix}
```

```math
X^\top=\begin{bmatrix}1&3\\2&4\end{bmatrix}
```

作用：

1.  改变矩阵结构
2.  使矩阵满足乘法维度要求
3.  计算变量之间的关系

------------------------------------------------------------------------

## 5. 为什么需要 XᵀX？

如果：

```math
X\in\mathbb{R}^{n\times p}
```

例如：

100个被试，5个变量：

```math
X\in\mathbb{R}^{100\times5}
```

那么：

```math
X^\top\in\mathbb{R}^{5\times100}
```

因此：

XᵀX：

```math
(5\times100)(100\times5)=5\times5
```

得到：

```math
5\times5
```

成为方阵。

这也是线性回归公式中出现 XᵀX 的原因。

------------------------------------------------------------------------

## 6. 矩阵求逆 X⁻¹

普通数字：

```math
5\times\frac{1}{5}=1
```

所以：

1/5 是 5 的逆。

矩阵逆：

如果：

```math
AA^{-1}=I
```

那么：

$A^{-1}$ 是 $A$ 的逆矩阵。

I 是单位矩阵，相当于数字中的 1。

------------------------------------------------------------------------

## 7. 矩阵逆的直觉

矩阵表示一种变换。

例如：

```math
\begin{bmatrix}2&0\\0&3\end{bmatrix}
```

会把：

```math
(x,y)
```

变成：

```math
(2x,3y)
```

逆矩阵：

```math
\begin{bmatrix}\frac{1}{2}&0\\0&\frac{1}{3}\end{bmatrix}
```

可以恢复原来的数据。

因此：

矩阵逆表示：

> 抵消一个矩阵带来的作用。

------------------------------------------------------------------------

## 8. 为什么只有方阵有普通逆？

普通逆需要同时满足：

```math
AA^{-1}=I
```

以及：

```math
A^{-1}A=I
```

只有行数和列数相同：

```math
n\times n
```

才可能成立。

所以：

普通矩阵逆只存在于方阵。

------------------------------------------------------------------------

## 9. 线性回归中的矩阵求逆

最小二乘估计：

```math
\hat\beta=(X^\top X)^{-1}X^\top Y
```

逻辑：

1.  XᵀY：计算变量和结果的关系
2.  XᵀX：计算变量之间的信息结构
3.  (XᵀX)⁻¹：反向消除变量之间影响
4.  得到最优参数 β

------------------------------------------------------------------------

## 10. 奇异矩阵（Singular Matrix）

定义：

奇异矩阵是没有逆矩阵的方阵。

原因：

信息丢失或变量重复。

------------------------------------------------------------------------

## 11. 奇异矩阵的直观理解

如果：

(x,y)

经过变换变成：

(x,0)

那么 y 信息消失。

看到：

(x,0)

无法知道原来的 y。

因此无法恢复，也没有逆。

------------------------------------------------------------------------

## 12. 判断奇异矩阵

对于方阵：

如果：

```math
\det(A)=0
```

则：

奇异矩阵。

如果：

```math
\det(A)\ne0
```

则：

可以求逆。

------------------------------------------------------------------------

## 13. 统计中的奇异矩阵

最常见原因：

多重共线性。

例如：

年龄和出生年份：

出生年份 = 当前年份 - 年龄

两个变量提供完全相同的信息。

导致：

```math
X^\top X
```

无法求逆。

------------------------------------------------------------------------

## 14. 奇异矩阵与模型问题

如果：

```math
(X^\top X)^{-1}
```

不存在：

则：

β 无法唯一估计。

表现：

-   参数不稳定
-   标准误增加
-   模型结果受数据扰动影响

------------------------------------------------------------------------

## 15. 核心总结

矩阵乘法：

> 加权组合变量，形成预测。

矩阵转置：

> 重新组织数据结构，使计算成立，并表达变量关系。

矩阵求逆：

> 抵消矩阵作用，从结果反推出未知量。

奇异矩阵：

> 信息重复或丢失，导致无法唯一恢复。

这些概念是理解：

-   GLM
-   fMRI design matrix
-   混合效应模型
-   Bayesian hierarchical model
-   机器学习模型

的基础。
