# 概率、独立性、互信息与条件互信息

> 本文经 AI 辅助核查，修复了公式和表格格式，补充定义条件，并修正独立性及 DFI 的解释。核查资料见文末，尚未经人工专家审定。

## 1. 本文要解决什么问题？

理解互信息（Mutual Information，MI）和条件互信息（Conditional Mutual Information，CMI），可以沿以下顺序学习：

1. 随机变量与具体取值；
2. 边缘概率、联合概率与条件概率；
3. 独立性与条件独立性；
4. MI 如何比较实际联合分布与独立时的分布；
5. CMI 如何在给定第三个变量后衡量统计依赖；
6. 这些概念怎样用于定向预测和定向特征信息（DFI）。

除第 8 节外，下面主要讨论离散变量。对数统一使用 $\log_2$，信息量的单位是 **bit（比特）**；若使用自然对数，单位则为 nat。

## 2. 随机变量与概率

### 2.1 随机变量与取值

随机变量是把随机试验的结果映射为数值的函数。例如抛一枚硬币，定义：

```math
X=
\begin{cases}
1, & \text{正面}\\
0, & \text{反面}
\end{cases}
```

公平硬币满足 $P(X=1)=P(X=0)=0.5$。需要区分：

- $X$：随机变量；
- $x$：变量可能取得的具体值；
- $P(X=x)$：变量取该值的概率。

对离散变量， $p_X(x)=P(X=x)$ 称为**概率质量函数**。下文在含义清楚时简写为 $p(x)$。

### 2.2 边缘概率与联合概率

**联合概率**描述多个取值同时发生的概率；**边缘概率**只描述其中一个变量：

```math
p(x,y)=P(X=x,Y=y),\qquad
p(x)=P(X=x),\qquad p(y)=P(Y=y)
```

例如， $X$、 $Y$ 分别表示两次抛硬币的结果， $P(X=1,Y=1)$ 表示两次都为正面的概率。本文用大写 P 表示事件概率，用小写 p 表示质量函数，避免混淆两种记号。

从联合分布得到边缘分布，需要对另一个变量的所有可能取值求和：

```math
p(x)=\sum_y p(x,y),\qquad
p(y)=\sum_x p(x,y)
```

这里的“边缘”不是更小的概率，而是只保留某些变量后的分布。

## 3. 条件概率与乘法公式

### 3.1 条件概率

条件概率描述“已经知道事件 B 发生时，事件 A 发生的概率”。当 $P(B)>0$ 时：

```math
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
```

其中 $A\cap B$ 表示两个事件同时发生。分母把考察范围缩小到满足 B 的结果，分子保留其中也满足 A 的结果。

对离散变量，当 $p(y)>0$ 时，同样有：

```math
p(x\mid y)=\frac{p(x,y)}{p(y)}
```

### 3.2 乘法公式

将定义两边乘以分母，得到：

```math
P(A\cap B)=P(A\mid B)P(B)
```

它**不要求独立**，但这里的条件概率要求 $P(B)>0$。若改写为 $P(B\mid A)P(A)$，则要求 $P(A)>0$。不要用上述比值直接定义零概率条件事件下的条件概率。

## 4. 独立性：何时可以直接相乘？

### 4.1 事件独立

事件 A、B 独立的通用定义是：

```math
P(A\cap B)=P(A)P(B)
```

这个定义也涵盖零概率事件。当 $P(B)>0$ 时，它等价于 $P(A\mid B)=P(A)$：知道 B 发生不改变 A 的概率。

因此，“联合概率等于条件概率乘边缘概率”是乘法公式；“联合概率等于两个边缘概率的乘积”还需要独立性。[条件概率与独立性定义][mit-probability]

### 4.2 随机变量独立

离散变量 X、Y 独立，当且仅当对所有取值组合都满足：

```math
p(x,y)=p(x)p(y)
```

- **一个相等的取值组合不能证明独立。**
- **一个不相等的取值组合就足以否定独立。**

独立也不等于互斥。若两个事件都有正概率且互斥，其联合概率为零，而边缘概率乘积为正，因此它们不独立。

### 4.3 两个例子

**独立抛硬币。**假设两次公平抛掷相互独立，两次都为正面的概率为 $0.5\times0.5=0.25$。独立性是这个例子的假设，不能仅由“两枚硬币都公平”推出。

**复习与考试。**从以下 100 名学生中等概率抽取一人：

| 复习情况 | 通过考试 | 未通过 | 合计 |
| --- | --- | --- | --- |
| 参加复习 | 40 | 10 | 50 |
| 未参加复习 | 10 | 40 | 50 |
| 合计 | 50 | 50 | 100 |

令 A 为参加复习，B 为通过考试，则：

```math
\begin{aligned}
P(A)&=P(B)=0.5,\\
P(A\cap B)&=0.4\ne 0.25=P(A)P(B),\\
P(B\mid A)&=\frac{40}{50}=0.8.
\end{aligned}
```

因此，两个事件不独立。这里将这 100 人的分布作为数学例子；若它们只是更大总体的样本，不能把样本比例的差异直接当作总体不独立的证明。统计依赖也不能单独证明复习的因果效果。

## 5. 互信息：如何量化统计依赖？

### 5.1 定义

互信息比较“实际联合分布”和“具有同样边缘分布、但假设独立时的联合分布”：

```math
I(X;Y)=\sum_{x,y}p(x,y)
\log_2\frac{p(x,y)}{p(x)p(y)}
```

理解公式可以分为三步：

1. 计算实际概率与独立基准概率的比值；
2. 取对数，判断该组合比独立基准更常见还是更少见；
3. 按实际联合分布加权平均。

当 $p(x,y)=0$ 时，对应求和项按零处理；当 $p(x,y)>0$ 时，两个边缘概率必为正。**单个对数比值可以为负，平均后的互信息非负。**它不是每个组合的“意外程度”的绝对值。[MI 定义与性质][mit-mi]

### 5.2 独立时为什么为零？

独立时，所有正联合概率处的比值都为 1，对数为零。反过来也成立：

```math
I(X;Y)=0
\quad\Longleftrightarrow\quad
X\perp Y
```

这里 $\perp$ 表示独立。这是**总体分布**的性质；有限样本估计为零或不为零，都不能直接替代统计推断。

### 5.3 与熵的关系

**熵**是离散变量的平均不确定性；**条件熵**是在给定另一个变量后，按该变量分布平均的剩余不确定性：

```math
H(Y)=-\sum_y p(y)\log_2 p(y)
```

```math
H(Y\mid X)=-\sum_{x,y}p(x,y)\log_2 p(y\mid x)
```

零概率处按零项处理。有限取值变量满足：

```math
I(X;Y)=H(Y)-H(Y\mid X)
```

所以 MI 表示：知道 X 后，Y 的不确定性**平均**减少多少，不是说每个具体的 X 取值都使不确定性减少。对于无限取值的离散变量，应检查相关熵是否有限，不能直接计算 $\infty-\infty$。[熵的定义与条件][mit-entropy]

### 5.4 重要性质与数值例子

- **对称**： $I(X;Y)=I(Y;X)$，本身不提供时间或因果方向。
- **非负**： $I(X;Y)\ge 0$，可以为无穷大。
- **不局限于线性关系**：MI 衡量整个分布的依赖；Pearson 相关系数主要描述线性关联。相关系数为零不等于独立。
- 对有限取值变量，MI 不超过任一变量的熵；MI 不是统一落在 0 到 1 之间的系数。

在复习与考试的例子中，把 A、B 分别编码为 0/1，四个联合概率为 0.4、0.1、0.1、0.4，独立基准均为 0.25：

```math
I(A;B)=2(0.4)\log_2\frac{0.4}{0.25}
+2(0.1)\log_2\frac{0.1}{0.25}
\approx 0.2781\ \text{bit}
```

## 6. 条件互信息：给定 Z 后还有多少依赖？

### 6.1 为什么需要条件化？

例如：

- X：颞中回前部（aMTG）的过去活动；
- Y：海马当前活动；
- Z：海马的过去活动。

海马当前活动可能已经能由它自己的过去活动预测。我们想问：**在给定 Z 后，X 还能提供多少关于 Y 的额外信息？**

这里的“给定”是统计条件化，不是实验操纵，也不等于已经排除了所有混杂因素。

### 6.2 定义

对离散变量：

```math
I(X;Y\mid Z)
=\sum_{\substack{z\\p(z)>0}}p(z)
\sum_{x,y}p(x,y\mid z)
\log_2\frac{p(x,y\mid z)}{p(x\mid z)p(y\mid z)}
```

先在每个正概率的条件 $Z=z$ 下比较两个分布，再按 $p(z)$ 平均：

| 分布 | 含义 |
| --- | --- |
| $p(x,y\mid z)$ | 条件下的实际联合分布 |
| $p(x\mid z)p(y\mid z)$ | 保持条件边缘分布、但假设条件独立时的基准 |

求和中的零条件联合概率项也按零处理。

### 6.3 为什么可以写成 KL 散度？

KL 散度衡量一个概率分布相对于另一个分布的差异。离散情形定义为：

```math
D_{\mathrm{KL}}(P\Vert Q)
=\sum_u P(u)\log_2\frac{P(u)}{Q(u)}
```

零分子项按零处理；若某处 $P(u)>0$ 但 $Q(u)=0$，散度为正无穷。KL 散度非负，但通常不对称，也不是通常意义的距离。

MI 是联合分布相对于边缘乘积分布的 KL 散度。CMI 则是条件下 KL 散度的平均：

```math
I(X;Y\mid Z)
=\sum_{\substack{z\\p(z)>0}}p(z)
D_{\mathrm{KL}}\!\left(
p_{X,Y\mid z}\,\Vert\,p_{X\mid z}p_{Y\mid z}
\right)
```

因此，CMI 非负，且等于零当且仅当：

```math
X\perp Y\mid Z
```

这表示**给定 Z 后，X 与 Y 条件独立**；离散情形需对每个正概率的 z 成立。它不表示 X、Y 各自与 Z 独立。[CMI 与条件独立][mit-mi]

有限取值变量还满足：

```math
I(X;Y\mid Z)=H(Y\mid Z)-H(Y\mid X,Z)
```

它衡量已经知道 Z 后，再知道 X 使 Y 的不确定性平均减少多少。无限取值时仍需避免未定义的熵差。

### 6.4 条件化可能减少依赖，也可能增加依赖

**CMI 不一定小于 MI。**“给定 Z 后的依赖”不应理解为从原 MI 中扣除一个非负部分。

**依赖消失的例子。**令 $X=Y=Z$，且 Z 为公平的 0/1 变量。X、Y 本来完全相同，MI 为 1 bit；给定 Z 后它们都已确定，所以 CMI 为 0。

**依赖出现的例子。**令 X、Y 为相互独立的公平 0/1 变量， $Z=X\oplus Y$。这里 $\oplus$ 是“异或”：两个值不同则为 1，相同则为 0。

| X | Y | Z | 联合概率 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 1/4 |
| 0 | 1 | 1 | 1/4 |
| 1 | 0 | 1 | 1/4 |
| 1 | 1 | 0 | 1/4 |

原本 X、Y 独立，MI 为 0。给定 Z 后，知道 X 就能确定 Y，因此：

```math
I(X;Y)=0,\qquad I(X;Y\mid Z)=1\ \text{bit}
```

这两个例子分别说明：条件独立不推出无条件独立，无条件独立也不推出条件独立。上面的数值可直接由表格和定义计算得到。

## 7. MI 与 CMI 的对比

| 比较维度 | MI | CMI |
| --- | --- | --- |
| 实际分布 | $p(x,y)$ | $p(x,y\mid z)$ |
| 独立基准 | $p(x)p(y)$ | $p(x\mid z)p(y\mid z)$ |
| 衡量对象 | X、Y 的总体统计依赖 | 给定 Z 后 X、Y 的统计依赖，按 Z 平均 |
| 等于零 | X、Y 独立 | 给定 Z 后 X、Y 条件独立 |
| 非负性与对称性 | 非负，交换 X、Y 不变 | 非负，交换 X、Y 不变 |
| 因果含义 | 本身不证明因果关系 | 条件化本身也不证明因果关系 |

## 8. 连续变量：密度不是精确取值的概率

对于具有概率密度的连续变量， $f_X(x)$ 是密度，不是 $P(X=x)$。单点概率为零，区间概率通过对密度积分得到。

当 X、Y **具有联合密度**时，独立等价于下式在几乎处处成立：

```math
f_{X,Y}(x,y)=f_X(x)f_Y(y)
```

“几乎处处”允许在对积分没有影响的零测度集合上例外。互信息的密度表达式为：

```math
I(X;Y)=\iint f_{X,Y}(x,y)
\log_2\frac{f_{X,Y}(x,y)}{f_X(x)f_Y(y)}
\,\mathrm{d}x\,\mathrm{d}y
```

若 X、Y、Z 具有联合密度，条件互信息可写为：

```math
I(X;Y\mid Z)=\iiint f_{X,Y,Z}(x,y,z)
\log_2\frac{f_{X,Y\mid Z}(x,y\mid z)}
{f_{X\mid Z}(x\mid z)f_{Y\mid Z}(y\mid z)}
\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z
```

条件密度只需在 $f_Z(z)>0$ 的区域定义，零密度项按通常约定处理。

需要保留三个区别：

1. 每个变量各自连续，不保证它们有普通的联合密度。例如连续 X 与 $Y=X$ 的联合分布集中在一条线上，不能直接套用上述二维密度积分。
2. 一般情况下应使用基于概率分布的 KL 定义。例如，具有密度的连续 X 与自身的 MI 为正无穷，并不是必然得到一个有限数。
3. 连续情形的熵应使用**微分熵**，不能直接套用离散熵公式；微分熵可以为负。相关量有限时，才可安全使用相应的熵差表达式。[连续信息量的处理][mit-entropy]

实际神经信号通常需要从有限数据估计 MI、CMI。应说明估计方法、时间历史、样本量及零模型；时间相关的数据不能随意当作独立样本打乱。

## 9. 怎样连接到定向信息与 DFI？

### 9.1 先分清两种“定向信息”记号

在神经信号分析中，过去与当前的角色可使 CMI 表达一个有时间方向的预测问题。Ince 等（2015）使用的时间分辨形式是：

```math
\mathrm{DI}_{X\to Y}(t,d)
=I(Y_t;X_{t-d}\mid Y_{t-d}),\qquad d>0
```

这里，源脑区的过去活动为 $X_{t-d}$，目标脑区的当前活动为 $Y_t$，目标脑区被条件化的过去活动为 $Y_{t-d}$。论文把这个滞后 CMI 称为 DI，并与传递熵（Transfer Entropy，TE）联系起来。[原论文 Methods，Step 2][dfi]

这是**只选一个过去时点的形式**。更一般的传递熵分析可以使用源和目标的一段历史；使用单时点还是历史向量，会改变条件化的信息及结果。

信息论中的 Massey 序列定向信息另有完整定义：

```math
I(X^n\to Y^n)=\sum_{t=1}^{n} I(X^t;Y_t\mid Y^{t-1})
```

其中 $X^t=(X_1,\ldots,X_t)$， $Y^{t-1}$ 类似，起始时的空历史不提供条件信息。这个定义包含源的截至当前历史，并对整段序列求和；不能不加说明地把它等同于上面的单滞后 CMI。[Massey 定向信息讲义][mit-di]

### 9.2 DFI 的原始差值定义

设 F 为指定的刺激、行为或认知特征，例如距离。沿用上述研究的单滞后记号，再定义：

```math
\mathrm{DI}_{\mid F}(t,d)
=I(Y_t;X_{t-d}\mid Y_{t-d},F)
```

这里 $\mathrm{DI}_{\mid F}$ 只是简写，不是对一个已经算出的 DI 数值再做条件化。Ince 等（2015）的 DFI 定义为两项的差：

```math
\begin{aligned}
\mathrm{DFI}_F(t,d)
={}&I(Y_t;X_{t-d}\mid Y_{t-d})\\
&-I(Y_t;X_{t-d}\mid Y_{t-d},F).
\end{aligned}
```

它比较：在同一个目标过去活动的条件下，进一步给定 F，源过去与目标当前之间的预测依赖改变多少。差值要求两项有限；不能计算 $\infty-\infty$。[原论文 Methods，Step 3][dfi]

### 9.3 为什么不能把 DFI 当作非负的“传递份额”？

两个 CMI 各自非负，但条件化可能增大 CMI，所以 **DFI 可以为正、为零或为负**。即使总体分布已知，负值也可能存在，不一定是估计误差。

- 正值：给定 F 后，该预测依赖减小。
- 负值：给定 F 后，该预测依赖增大。
- 零值：两种条件化下的信息量相等，不能据此断言 F 与整个网络无关。

这个差值可能混合**冗余信息**（两个变量提供重叠的特征信息）和**协同信息**（需要联合知道两个变量才能获得的特征信息）。因此，不应直接把 DFI 当作必非负、可独立相加的特征传递量。[原始定义及解释限制][dfi]

另外，时间方向和额外预测信息不自动证明直接的因果传递。未测量的共同输入、目标历史选择及相关特征都可能影响结果；只分析一个 F，也不等于排除了其他特征的影响。

## 10. 复习要点

| 概念 | 核心问题或区别 |
| --- | --- |
| 联合概率 | 多个事件或取值同时发生的概率 |
| 条件概率 | 限定在条件事件内，重新计算概率 |
| 独立性 | 整个联合分布是否等于边缘分布乘积 |
| MI | 实际联合分布与独立基准相差多少 |
| CMI | 给定 Z 后，实际条件分布与条件独立基准相差多少 |
| 条件化 | 可以减少或增加 MI；不是统一的“扣除影响”操作 |
| 时间定向 CMI | 源过去是否提供目标过去之外的额外预测信息 |
| DFI | 进一步给定 F 前后两个定向 CMI 的有符号差值 |
